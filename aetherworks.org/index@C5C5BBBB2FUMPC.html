UMPCあらかると

　国内ではVAIO Uが市場を開拓し、海外ではOrigamiの名で騒がれた、UMPC（Ultra Mobile PC:超小型パソコン）について語ってみる。
　UMPC全般に関する説明はWikipedia:UMPCに任せ、ここでは個別のUMPCについて書く。といっても定義が微妙なので、重さ1キロ未満*1でDOS/V相当の機能を備えたノートパソコンを取り扱うことにする。

▲ ▼

主な機種

　主な、というか天稀が調べたり実際に触った機種。

▲ ▼

Panasonic Let's note Rシリーズ

　10.4型ノートはUMPCとは言えないし、実際チップセットなども普通のノートPCなのだが、基準を満たす軽さなので取り上げる。
　頑丈さとバッテリー持続時間が売りのレッツノートで、もっとも小型のRシリーズは7世代全てで重さ1キロを切っている。特にR6が軽量で、次にくる公人舎SA/SHより軽い。
　以下はそのR6のスペック。

Type:    10.4インチ ノート型
MaxDest: 1024*768
Weight:  930g
Battery: 8時間

　バリバリのゲーム用途でもない限り、必要充分をはるかに凌ぐ性能がある。ゲームもある程度までなら余裕で動く。
　歩きながら使うのは無理なサイズと構造だが、軽いため携行性は充分にあり、しかもバッテリー駆動時間もとても長いので小旅行程度ならACアダプタを持ち歩く必要がない。
　普通にメイン用途にできるスペックを持つため、通常時と外出時とで殆ど変わらぬ使い方ができる。座った時に使えれば充分というなら、選択肢にしていい。

　ただ難点は、高いことか。あと、R6は旧機種なのでだんだん入手が難しくなっているのと、R7でファンレスを諦めてしまったこと。

▲ ▼

ASUS EeePC

　大きさ以外の意味で規格外のUMPC。5万円を切る価格に、容量と画面サイズ以外はおおむね十分な機能と性能を搭載している。

Type:    7インチワイド ノート型
MaxDest: 800*480*10
Weight:  約920g
Battery: 公称3時間

　とにかく厄介なのがデータ容量。SSDなので耐衝撃と電力節約には優れるのだが、総容量が4GBしかない。初期状態で半分以上、WindowsUpdateをかけると空き容量が1GBを切る。SDHCが付属しているらしいので、可能な限りデータを移してしまった方がよい。メインのデータ保存は当然そちら。
　画面の小ささも問題になることが多い。縦480だとWindowsのUIでさえOKボタンが画面外になることが多々ある。対処は可能だがそのあたりは割り切りが必要。
　あとの欠点はPC/CFカードスロットがないことくらいで、それ以外の拡張性は充分、性能もゲーム（東方永夜抄）が普通に動くほどあるので軽作業用としては充分なものを備えていると思う。まぁでも容量不足でOfficeは厳しいか。

　ストレージの貧弱さがあるからメイン機には絶対なれないけど、ネット専用サブマシンとしてはいけるかも。8GBタイプが出れば少し余裕が出てソフトが入るので、もう少し何かできそうな気がする。
　なお、バッテリーはそう多いわけではないので、出がけにバリバリ使っていると電池が無くなるかもしれない。

▲ ▼

工人舎 SAシリーズ

　発売当初、そのサイズと価格の安さで話題になった、7型ワイド液晶の小型ノートパソコン。型番の頭四文字から『財布（SA1F）』と呼ばれる。
　おそらくこれが、タッチタイピング可能なフルキーボードを載せるのに限界のサイズだろう。UMPCと言えるかどうかは、ちと微妙なところ。
　タッチパッドとスティックポインタが両方あるのは、ちょっと面白い。最終型は画面がタッチパネルになっており、ポインティングデバイスが３つあることに。

Type:    7インチワイド ノート型
MaxDest: 800*480*11
Weight:  960g*12
Battery: 公称5時間*13

　発売当初は話題になったSAシリーズだが、小形かつ安価を目指したためか細部の構造にいくつも難点があり、メイン用途にするには辛い性能と感じた。最終モデルではタッチパネルを搭載するが、ペンは内蔵できず専用ケースについたポケットに入れるという点も地味にマイナス。
　バッテリー駆動時間はまあまあ良いので、外出時用に特化したチューニングと用途に徹するのが正しいと思う。

　今から買う場合、よほど予算が逼迫しているのでなければ、SHなど他の機種を考慮に入れた方がいい。

▲ ▼

工人舎 SHシリーズ

　SAシリーズの後継機となる、7型ワイド液晶の小型ノートパソコン。SAとほぼ同等のサイズだが、スペックは一回り強化されている。
　次にくるLOOX Uとほぼ同等スペックのため、よく比較される。
　SA最終型と同じく、タッチパッド・スティックポインタ・タッチパネルがそろっている。

Type:    7インチワイド ノート型
MaxDest: 1024*600
Weight:  993g*14
Battery: 公称3.5時間*15

　SAが持っていた欠点を軒並み改善し、タッチパネルとワンセグを標準搭載、全般的に性能が向上した。ただしOSがVistaになっており、少々重い。XPへの換装を行うと一部ボタンが使用不能になるが、それでもXPに載せかえたほうがいいと思う。
　ハード性能向上のあおりでファンが載ったが、停止させることも可能。またバッテリー駆動時間も3.5時間と短くなったが、そこは運用で対処か。

　SHはある程度の性能を確保しているので、その性能に満足できるならメインでの使用も可能だろう。
　パソコンはあくまでタッチタイピング、という場合はもっとも小型なのがこの機種だ。OSがXPであれば使い勝手も抜群で、実に優秀。

▲ ▼

工人舎 SRシリーズ

　SHの次に出てきた、DVDスーパーマルチドライブ搭載モデル。スペックはおおむねSHと同等だが、DVDドライブを内蔵し、そのスペース確保のためにHDDは1.8インチ。
　『小型がいい、でもドライブは必須』という場合はコレ。ただしXP化はまだまだ不完全の模様。DVD載せた分重いし、1.8インチHDDのため速度が遅い（らしい）のも難点。

　1.8インチHDDのせいなのか、ちまたではあまり人気がなさそうなんだよねぇ……

▲ ▼

Fujitsu LOOX P

　工人舎の7インチシリーズとだいたい同じ大きさのタブレットPC。
　ポインティングはタッチパネルとスティックポインタ。

Type:    8.9インチワイド ノート型
MaxDest: 1280*768
Weight:  960g〜1150g*16
Battery: 標準4.9時間/大型10時間

　ちょっと前の機種だと画面1024*768だったかもしれないが、とにかく解像度はSHより一回り上。ただしHDDは1.8インチが載っていて速度は遅くなる。値段もちょっと高め。
　HDDのアクセス速度より画面の広さを確保したい、金にも糸目をつけない、という人は工人舎よりこちらがいいかも。

▲ ▼

Fujitsu LOOX U

　初期モデルがLOOX U50WNのため、英字部分だけ取り出してるっきゅん（LOOXUWN）と呼ばれる。
　5.6型ワイド液晶（1024*600）を積んだクラムシェル型で、CPU/RAM/VGAがKohjinsha SH8と同等。ただしHDDが1.8インチタイプなので、小型なぶん容量やデータ転送速度は劣る。
　工人舎SHと性能は似通っているが、デバイスは若干少なめ。ポインティングはタッチパネルとスティックポインタで、タッチパッドは無い。

Type:    5.6インチワイド クラムシェル型
MaxDest: 1024*600
Weight:  599g*17
Battery: 3.8時間*18

　タイピングも親指打法も可能に設計したキーボードだが、その配列の癖の強さが最大の欠点。特に、方向キーや『ー』キーの入力がFnキー併用となっているのは、モノ書きにとっては非常に使い辛い。
　キーをカスタマイズするとある程度解消できるが、かわりに犠牲にするキーを選定する必要がある。また外付けキーボードの配列もカスタマイズしてしまうので注意が必要。
　なお、キーボードを照らすライトがあるが、実際に使用してみた感覚では、あまり役に立たない。

　ちょっと難点はあるが、キーボードを除けば機能は考えて盛り込まれており、UMPCとしては無難な機器である。Bluetooth内蔵のアスキーコラボモデルならば、さらに便利かもしれない。
　自宅内でも使用する場合、別売りのスタンド型ポートリプリケータがあるとなお便利。

　HDD収納スロットの展開が簡単なので、いざというときHDD交換がユーザーでも簡単にできるのは、地味に安心かもしれない。

▲ ▼

Sony VAIO typeU

　まさか、この自分が、ソニータイマーの存在をかなり本気で信じている*2自分が、ソニーの製品を検討することになるとはっ
　つわけで、UMPCという言葉が出来る以前にSonyが発売した、超小型PC。大きさ・形状・用途としては明らかにUMPCなのだが、チップセットはUMPC用ではなく、性能はかなりのものがあるらしい。

Type:    5.6インチワイド タブレット型（スライド式キーボード）
MaxDest: 1024*600
Weight:  532g*19
Battery: 3.5時間*20

　LOOX Uよりちょっと高めだが、ポートリプリケータが標準添付。
　電源スイッチに『省電力ロック』のモードがある。操作しない時はこのスイッチを入れておけば、電池の消耗が抑えられ復帰もPDA並みに素早い。どの程度消耗が抑えられるかは不明だが、かなり感心した機能だ。

　欠点はやはりキーボード。構造的に押しづらく、執筆用途には耐えない。暗所でも使えるようLEDが入っているが、キーボード自体が使いづらいので、あまり便利にならない。
　使用可能な場所では外付けキーボードを使った方がいい。家ではポートリプリケータ付きのUSBキーボード、外ではBluetoothキーボードがおすすめ。

　ソニータイマーを考慮に入れない場合、総合的にはけっこう優秀かもしれない。してやられた、という感じだ。
　本体キーボードでの入力をあまり考えなくていい人や、デザインが気に入った人など向けだ。

　なおソニータイマー対策で3年保証を強く推奨。保証が有効な使用法しかしないのであればソニータイマー対策に三年保証が有効なのだが、内蔵ドライブ交換はもちろん、OS入れ替えでも保証がなくなる。WindowsVistaが実用に耐えないOSなだけに、性能を諦めるか保証を諦めるかの嫌な二択になる。

▲ ▼

Sharp/WILLCOM D4

　WILLCOMの通信デバイスを内蔵するUMPC。大きさや形状はVAIO UやOQOと似た感じ。というよりOQOとはほぼ完全に競合しそう。
　W-Simと無線LANが内蔵なので通信はそんなに困らないと思うが、OQO同様にCFスロットがないので、高速回線を利用するにはUSBのデバイスが要る。

　まだサイトでの情報公開や告知のみで、カタログ等が出回っていないため詳細は不明だが、持って使う分には便利そうな機種。少なくとも今後買うなら、馬鹿高いOQOを買うよりはこっちを選んだ方がいい。
　……と思うんだが。マニアにはOQOが堪らないらしいなぁ。あれはなんか重大な欠陥を抱えてるっぽいんだけど。

　ちなみに、横幅がなんとLOOX Uよりわずかに大きい。すなわち、両手で持って親指でキーボードを押すと、中央付近のキーはちょっと押しづらいと思う。
　覚悟して使え。

▲ ▼

OQO model 02

　米OQO社の本格UMPC。重量450g。日本向けのモデルはない*3。

Type:    5インチワイド タブレット型（スライド式キーボード）
MaxDest: 800*480*21
Weight:  約450g*22
Battery: 3時間*23

　キーボードの弱いUMPCが多い中で、OQOのキーボードは親指打法でのキー入力がしやすい。ただし英語キーボードで、【半角/全角】など日本語固有のキーはないため注意が必要。タッチタイピングはできないが、それが必要な状況ではUSBかBluetoothの外付けキーボードを使うといいだろう。
　タッチパネルは磁気式で、圧力で勝手に入力してしまう心配はない。しかしペンは専用のものが必要になり、別売り*4の上に内蔵できない。スティックポインタやマウスを使うのが無難かもしれない。
　CFスロットがないためCF型通信カードが使用不可なのもマイナス。

　よく設計されていると思っていたが、ディスプレイ配線の接触が弱いらしく、表示が故障しやすい。店頭展示３店、通信販売１店のいずれでも故障の話を聞いたので、ちょっと雑な使い方したらすぐ壊れるのだろう。
　日本でのサポート体制と価格を考えると、趣味的な理由がない限りは手を出すべきではないと思う。ブルレーは他にも変わったUMPCを多数取り扱うが、保証についての体制はどの製品もだいたい同じ。

▲ ▼

OQO model 01+

　米OQO社のUMPC前世代モデル。model2より一回り小さく、重さ約400g。やはり日本向けモデルはない。
　WindowsXPが動作する世界最小のフルキーボード搭載コンピュータ、らしい。スペック不足でVistaは載らない。

Type:    5インチワイド タブレット型（スライド式キーボード）
MaxDest: 800*480*24
Weight:  398g*25
Battery: 3時間*26

　大まかな形状はmodel2とそう変わらないが、ひとまわり小さいこの機種はなんとSL-Zaurusと同等サイズ。完全にPDAのサイズでWindowsが動く。
　スティックポインタが標準添付で内蔵可能。ただスペックが乏しいため動作が少々重い*5。model01用のポートリプリケータがない*6のも地味にマイナスかもしれない。

▲ ▼

Sharp Zaurus SL-C3200

　これはUMPCではなくPDAなのだが、パソコンに迫る多機能性を持つため比較対象として書いておく。

Type:    3.7インチ クラムシェル型
MaxDest: 640*480
Weight:  約298g
Battery: 約7時間

　OSには専用カスタマイズされたLinuxが使われているため、PC向けにコーディングされたソフトをZaurus用にコンパイルして使用することも可能（ApacheだのSambaだのが動く）。あくまでもPDAだし、処理性能はWin95時代のPentium並なので、現在のPC並の処理をこなそうと思うと無理はあるのだが。
　ただし逆に、スイッチを押して1秒程度で操作可能になるという、PCには望むべくも無い便利な性質もある。といってもこのあたりは用途の違いであろうか。

　さて、このZaurusがUMPCと同じ土俵で比較ができる要素といえば、キー入力。
　両手で持って親指2本でキー入力を行う使用スタイルの場合、Zaurusのキー入力のしやすさは他のPDA/スマートフォンやUMPCを圧倒する。同社のスマートフォンはボタンが小さすぎたり大きすぎたり配列が悪かったりでZaurusほど押しやすくはなく、VAIO Uのキーボードはもう論外と言っていい。私見だがD4も、キー間隔がないし中央付近のキーが指から遠いため、若干押しづらいのではないか。
　UMPCで近いキー操作感を持つのはOQO e2であるが、英語キーボードなのもあって実際には触れてみないとよくわからないところ。

総評

　比較にあたって、どういう性質を評価すべきか。
　まず、UMPCな機器として重要な要素を考えた。持ち運びのしやすさ（携行性）、バッテリー駆動時間、画面の解像度、そして処理性能といったところだろう。前者ほど重要。処理性能はそれほど重要でもないというか、小型機で性能の要るような処理をするのがムチャだというのは重々承知だが、それでも軽いソフトならストレス無く軽快に動いてくれるようでないと困る。
　次に、考えうる使用形態を大まかに『家での使用*7』『出先での使用*8』『持って使用*9』と3つ挙げて、それぞれ使い勝手などを評価した。
　最後に、機器の価格と、故障などの場合のサポートの評価。

　以上の項目を、調査結果と触感とカンでさっくりと評価してみたのが、下の表。なおレッツノートはR6を評価した。

　あくまでも私観に基づくものなので、参考にする際は注意してほしい。
