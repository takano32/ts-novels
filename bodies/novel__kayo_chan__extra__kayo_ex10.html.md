	登場人物 :

	 真城 華代 : 謎のセールスレディ。国籍 年齢 すべてが謎。

	 兵役がイヤな男たち :

	  利秀(トシヒデ) : 20代 前半の男。すごい女顔。

	  端彦(ツマヒコ) : 20代 前半の男。長髪で背が高い。

	  祥重(サチエ) : 20代 後半の男。蒼白な顔で、からだが虚弱そうに見える。三人のなかで唯一、兵役が終わった。

----

(幕が上がるとなにも見えない暗い舞台。舞台右手に照明が入る。その真ん中に華代が立っている。)

華代 : (観客のほうへ挨拶する) こんにちは、初めまして。私は真城華代と申します。
       最近は本当に心の寂しい人ばかり。そんな皆さんの為に私は活動しています。
       まだまだ未熟ですけれども、たまたま私が通りかかりましたとき、
       お悩みなどございましたら是非ともお申しつけ下さい。
       私に出来る範囲で依頼人の方のお悩みを露散させてご覧に入れましょう。
       どうぞお気軽にお申しつけ下さいませ。(観客席、「報酬は?」と騒ぐ)
       え? 報酬ですか？ (「いいえ」の意味で手を振りながら) いえ、お金は頂いておりません。
       お客様が満足頂ければ、それが何よりの報酬でございます。
     　さて、今回のお客様は… (左手に向かって手を指す)

(右手の照明が消されて、反対に左手の照明が入る。その中にソファーがあり、
 利秀、端彦、祥重の三人が座っている。)

利秀 : (祥重に) 動員予備軍訓練、どうだった?
祥重 : はあ… そんなの、つまらないのに決まってるじゃない。はっきり言って時間の浪費だわ。
       罰金はらってもいいからほかになんかをするほうがお得だと思うぐらいだよ。
利秀 : へ〜そっか。それでも兵役終わってから何年も訓練受けるなんて確かに面倒くさいなー
祥重 : そういえばあんたらはまだ軍隊行ってなかったんじゃないか。
       いつも免除免除と言っても、免除って言葉だけで易しくできるものではないよ。
       世の中はそんなに甘くないから…
端彦 : (神経質的に) そんなのわかってる。努力はしているから。
祥重 : いや だからと言うけど、わたしから見るとあんたはまだマジだけど、
       利秀はまったく努力していないみたい。
利秀 : (むかつく) なんだと? 僕がなにを努力していないんだと?
祥重 : だって、あんた免除って言うばかりで、別にこれっといえる免許を持っているのもないし、
       どっこも病気とか障害とかないじゃない。それに、カラの病気さえつくろうともしていないから。
       そうしているといつ引っ張られてしまってもおかしくはないわよ。
       それに、免除だけで終わることじゃないわ。
利秀 : くう〜
端彦 : (得意げに) わははは、だから俺様はカラの精神病を演じているぞー！
       それで診断書を受けて免除を受ければバッチリさ！
祥重 : 端彦、軍隊はそうして免除されても、後はどうする? あんた創業でもする気?
       どこの会社が精神病のある人を雇うのよ?
端彦 : (「しまった」の表情で) だああー! そうだった!
祥重 : だから、免除だけで終わりじゃないと言ったじゃない。
端彦,利秀 : はあ… どっちにしても厄介だなー
祥重 : そんなにイヤなら、いっそ自殺でもすればいいじゃない。屍には兵役がないから。
端彦 : (立ち上がって両手を広げて振りながら) 俺様がそんなこと、するかよ!
       第一、兵役を免除してもらおうとするのは人生をもっと楽しくすごすためだ!
       そこで死んでしまえばなんの意味があるのかよ!
祥重 : (迫力に押さえて作り笑いをしながら) じょ、冗談だよ、ジ・ョ・ウ・ダ・ン!

(三人の動きがその状態で止まる。左手の照明が暗くなり、右手の照明が入る。)

華代 : はい、やはり兵役はどの方にも厄介なものですね。
       あの方々の悩みを解決してあげることにしましょう。
       (そういいながらソファーの右の端ぐらいまで移動する。
       照明も華代を従って左に移動し、三人を照らす。端彦は立っているまま)
       お兄さんたちは、それが悩みですか?

(意外な人物の出現でびっくりする三人。端彦、ゆっくり座る。)

祥重 : あんたは?
華代 : はい、わたしはこんなものです。
       (いつもの名刺を三人に渡す、祥重は名刺を受けてそのまま側に置く)
端彦,利秀 : なになに? 「ココロとカラダの悩み、お受け致します。真城 華代」…か。
華代 : で、お兄さん達は兵役がいやで、それを免除してもらうのが望みですか?
利秀 : はあー僕が金持ちだったらいっそワイロでも使って免除してもらいたい。
華代 : あとの就職とかも考えれば「カラの病気」とかも危ないですね。
端彦 : そそ。なんかいい方法はないのかい? さすがの俺様でも精神病があることになってしまえば
       就職が面倒になるから。
華代 : へえー そうなんだ。じゃあ、よーするに、お兄さんたちは軍隊に行かなくてもよくて、
       後の就職にも問題がない状態になるといいんですね。
利秀 : それはそうですけど… できる?
華代 : そのぐらいなら朝飯前だよ。
端彦 : へえーそっか。で…どうするんだよ?
利秀 : そんに簡単なら僕にもしてくれるのかね?
華代 : もちろんです、では… それっ!!
       (その瞬間、舞台の下から竜巻が吹いて端彦と利秀を巻きこむ)
端彦,利秀 : ？？？？

(照明が左にちょっと動いて華代は照明からはずれる。その隙に華代は真っ暗の元の位置へ戻る。)

祥重 : なんだったんかな、あのコは?
端彦 : (胸に手を当たってみる) うん? なんか胸がくすぐったいか…
利秀 : (あっけなく) なんか脚にちからが入れない…
祥重 : え? あんたたちいきなりどうした?
端彦 : (すでに完全な女声で) お・・・俺様が知るか? (その間に胸が膨らむ)
利秀 : (同じく完全な女声で) …端彦、あなたのその声は裏声? …ってぼくも? (パニックする)
祥重 : (驚いた表情) どうしたのよ、二人とも!
利秀 : (とんでもなく長くなった髪と膨らんでしまった胸を手にして狼狽しながら)
       ぼ、僕が知りたいよ、そんなの!
端彦 : それにしてもおまえ、俺様より胸が大きくなったじゃないか…
祥重 : (扇子で端彦のアタマにヒット) いまそれをつっこむ時かよ!

(左手の照明が消されて真っ暗になり、右手の照明が入って華代を照らす。)

華代 : 今回の依頼もまさに朝飯前でした。
       兵役がいやなら、兵役の義務がない女性になったら一安心だね。
       皆兵制でも女性まで兵役の義務がある国は少ないから。
       それに後の就職とかを考えたらやっぱりへんなカラの病気を作るなどの
       危ないマネよりはこっちのほうがずっとマシでしょう。
       それであの二人さん、今夜は安心して眠れそうです。
     　さて、何か困ったことがありましたら何なりとお申しつけ下さい。
       今度はあなたの街にお邪魔するかもしれません。
       ……それではまた。

(華代、挨拶して舞台の右端に退場するかすぐ再登場する。)

華代 : ですけど…そういえばあの弱そうなお兄さんはなぜ変身しなかったんでしょう?

(華代、舞台の右端に退場する。幕が下がる)

----

*.「カラの病気」は「仮病」のことです。

-後書き-

日本には兵役の義務がありませんと知っていますが… わたしの国にはあります。

少ない奇特な例外は有っても、大体のひとには面倒でイヤな存在なだけです。

だから9月初に動員予備軍訓練から帰るときに思い付きで適当に書けたもので、

登場人物の名前とかもずいぶんいい加減で付けたものです。

小説形式ではつまらないかと思って戯曲の形式にしてみました。

でもこんな面白くない戯曲はまずありえないですね。ｍ(＿ ＿)ｍ
