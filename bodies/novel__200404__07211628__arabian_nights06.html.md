# 新世紀アラビアンナイト６

作：雅良生

----

「地中海が断ち切られたあたりに、アレキサンドリアの大灯台はそびえたつ。帆船で港湾の中に乗り入れば 、海岸に見える家々は、手を伸ばせば届くかのようだ。海から吹きつける風は、日暮れ時から強くなってきた。風よ、祈りの時刻を告げるミュエジンの声をナイルの上流にある町々まで届けておくれ。そして心あれば伝えてよ。平和こそ信仰の証しであることを。しかし、風は港湾の中の船たちを吹き散らすばかり。小さな船は、狩人に追われる獣のように逃げ惑う。船中から眺めれば、港湾の中に突き出した突堤の上の小道に立って手を振る人が見えた。船の中から手をあげて呼ぼうとしたが、風をはらんだ帆は船を走らせて、たちまちのうちに、人影を後ろの方に去らせてしまった。」

この詩の作者ドリーア・シャフィークは詩人としてよりも、エジプト革命のきっかけをつくった女性として知られている。１９５１年にドリーア・シャフィークは１０００名あまりの女性たちを引き連れてカイロ市内をデモ行進したあと、国会を取り囲み、３時間以上も議事を中断させて交渉した結果、国家財政の破綻と国民の困窮を救済するために全力を尽くすとの誓約書を書かせた。

しかし、この事件から２週間たち３週間たっても国政に何の変化も起こらないことにぶちきれたドリーア・シャフィークは、ウージー機関銃で武装した女性コマンド部隊「ナイルの若き娘達」に命じて、カイロ市内の主だった銀行の本支店を占拠させた。そして官僚と国会議員と国王一家の預金の出し入れ記録と、海外へ預けだされた資金の流れを暴露して新聞に掲載させた。

新聞を読んだエジプト国民は、そのあまりのひどさに激昂してゼネストに突入した。やがて混乱は暴徒化し、事実上の国家の崩壊に顔面蒼白となった要人たちは、先を争うように職を辞し国外に脱出した。その後は軍部に担ぎ出されたナセルが破産管財人のようなかたちで、混乱した事態の収拾にあたることになる。ナセルは混乱がおさまると、国家財政の破綻は英国によるスエズ運河の横領にあると看破して、運河を接収し、これを止めようとした英国とイスラエル軍との戦争を始めた。第２次中東戦争の始まりである。

軍事的敗北を外交的成功でおぎなって、スエズ運河の奪還に成功したナセルの声望は高まり、ほとんど神に近い存在になった。このとき、エジプト国民にして唯一人ナセルを批判したのがドリーア・シャフィークである。「思い上がるな、ナセル！お前の引き起こした戦争は高くつくものになる。近い将来われわれはスエズ運河のみならず、シナイ半島の大部分を失うことになるだろう。」しかし、エジプトの未来を予見した彼女の声明は一般大衆を激昂させた。世論に押された官憲によって自宅軟禁されるに及んで、彼女は自ら食を断ち、餓死しておわった。

ドリーア・シャフィークの詩碑のたつアレキサンドリアの海岸通りに、スーパー銭湯クブラカーンが開業したのは、１９９４年のことである。オスロ合意による平和の到来によって始まった外資の流入により、エジプト経済が上向くことを見込んだ内需プロジェクトのひとつで、事業主は、アラビア半島の湾岸地域に本拠を置く多国籍企業オーマン・コンツェルンだ。

天然鉱泉を利用した大小の浴場、ウオータースライダーを備えた温水プール、パーティー用の各種ホール、エジプト料理・トルコ料理・アラブ料理の定番に加えて世界中の料理を味わわせてくれるレストラン、ゲームセンター、マッサージパーラー、アスレチックジム、ショッピングプラザ、簡易宿泊施設を備えた施設は、今ではアレキサンドリアの新名所のひとつとなっている。

エジプト人の風呂好きは、トルコ帝国領であった時代に始まったものだが、結婚式に先立って銭湯でおこなわれる女たちの祝いは、エジプトならではの珍しい習慣である。花嫁の女親族、花嫁の女友達、嫁ぎ先の女親族、嫁ぎ先の隣近所の女性達が、同じ風呂につかってくつろいだ後、パーティーを催すのは、慣れない土地で暮らすことになる花嫁へのいたわりからきた習慣に違いない。その日もクブラカーン１Ｆのアメニティーホールでは、風呂から上がって乳香をまとった、初々しい１７歳の花嫁を迎える女たちの祝いが始まっていた。

親族と花嫁の挨拶がおわり、嫁ぎ先の隣近所の子供達による合唱が始まった。「花嫁さん、いらっしゃい。何でも相談に来てちょうだい。女は女同士、皆あなたの味方なんだから。」可愛らしい合唱がおわると、花嫁の側から、菓子袋がふるまわれた。菓子袋の外側にはエジプトのテレビで放映中の人気の日本アニメ「蜜蜂マーヤの冒険」のキャラがプリントされていた。

子供達に菓子袋を配ったメイドは、ホールの隅に下がると、お下げ髪のもう一人のメイドに、「これで、あがらせてもらうわ。」「そんなー、私１人じゃ無理ですよー。」「代わりにムスターファが来るから。後はよろしく。」メイドは、パントリーに下がると、ぱっぱと裸になって、社員に服装に乱れがないかチェックさせるために置いてある鏡に向かい、セフォラのパウダー・ブラッシュでファウンデーションをつくった。アワーグラスのリップスティックで唇に紅をさす。シャネルのマスカラを付けて目をパッチリさせる。タンクトップをつけて、ジーンズをはく。掌ほどもあるシルバーのバックルのついたベルトを締め終わると、黒の手袋をして黒のブルカをすっぽり頭からかぶった。着替え終わると、抜き足、差し足でパントリーからバックヤードに向かった。

突然、後ろから伸びた手が、メイドの胸をつかんだ。「こらっ、ムスターファ、何をする？」黒服に蝶ネクタイをした精悍なベドウィンは、メイドの胸のポケットから、紙片を取り上げ読み上げた。「午前２時起床、本社からのメールの確認。各現場における事故の有無の確認と指示と関係諸機関に対するお詫びのメールの送信。決裁の送信。未決および条件付決済の送信。却下の理由と再提出の際の注意点の送信。朝礼時の訓示の送信。全社員の家族の慶弔の有無の確認と喜捨と香典の指示。毎日遊んでばかりと思ったら仕事もしているらしい。」

メイドのまとわりつく手を払いのけて、ムスターファは、続けて読み上げる。「午前４時入浴。食事（モロヘイヤ、昨日のマハシー、焼きサラダ）。勉強（日本語ＣＤ、日本経済史）。午前７時出勤。請書確認。２Ｆ喫茶室の清掃、食材搬入、コーヒー・シャイの準備、午前８時開店、午前９時交代、ドリンク仕入れ、午前１０時３Ｆ大レストラン清掃、午前１０時半１Ｆアメニティーホール料理出し、午前１１時女たちの祝いの開始、午前１１時半あがり。午前１２時退出。午前１２時半授業開始。午後５時終業。買い物。また新しい服や化粧品を購入なさるのか？」

くだんのメイドが、可愛い頬をぷっと膨らませてそっぽを向くと、ムスターファは険しい一瞥をなげかけておいて、続きを読んだ。「午後７時出勤。３Ｆ大レストラン接客、宴会のヘルプ。後片付け、午後９時半オーダーストップ、午後１０時クローズ、食事（残り物）、午後１１時帰宅、入浴、就寝。翌朝は午前２時起床。あれー私とエッチする時間が書いてないじゃありませんか？」

「冗談はよしこさん。返してよ。」ムスターファは、素直に紙片を返すと改まった口調で言った。「タスク最高執行役員、あなたのお仕事は管理なさることです。手足を使ってする仕事はお遊びです。しかも毎日２時間しか睡眠をとってらっしゃらない。じつに嘆かわしい。天国から下界を見下ろしておられるお祖父様が、お嘆きになって涙を流される様子が目に見えるようです。」

「そんなこと分かっているよ。僕だって遊びでこんなことをしているわけじゃない。本業の土木建設業の足をひっぱっているこの施設の赤字を何とかするための調査をしてるんだ。」

「ほー、それで何か分かりましたか？」

「約２００項目、特に営業と仕入れに問題が集中している。が、一番の問題は社員の危機感のなさ。赤字でも本社がなんとかしてくれるという依頼心がこの施設をダメにしている。」

「それで対策は？」

「社員のやる気をたかめるんだ。個々人の自覚によって仕入れや業務から無駄を省き、従業員営業によって顧客を増やす。」

「ナポレオンのリーダーシップの原則を覚えてらっしゃいますね。部下の心を掌握して目的を遂行するためには、１に脅迫、２に恐怖、３にやる気の喚起であって、その中でももっとも容易で効果があるのが脅迫で、もっとも困難で効果が薄いのがやる気の喚起です。ナポレオンが実際に経験したやる気の喚起の実例は、まだ大尉時代にツーロンを攻略した際の上司で７０歳の老将軍の例があるだけでした。この将軍は、半世紀以上も軍に身を置いてきたベテランでしかも、部下のやる気の喚起を命がけでなしとげたのです。あなたにその真似ができますか？」

「うん、がんばってみる。もう学校に行く時間だから、行くね。」

タスクは、あたふたと廊下を走って、通用口のほうへいった。出口でスリッパをブーツに履き替えた。「おつかれさま。」受付の女の子に挨拶して外に飛び出した。

大浴場の下部の地階の壁に沿って坂を下りていくと、ボイラー室の側につくられた物干し場の傍にさしかっかった。呼び止められないように、さっと通り過ぎようとしたが、遅かった。

「タミヤ！洗濯物は取り込んでおいたわよ。」

「それは、どーも。」

「寮の掃除の方は頼むわね。」

「ジャスト待ったモーメント！今日の掃除当番は、ラビアさんでしょう？困りますよ。今から学校なのに。」

「汝ら、何事であれ善をなせば、決して無にされることはない（コーラン３−１１１）お互いあいみ互いと言うでしょう。私はこれからデートなのよ。トイレの臭いなんか付けて行けると思う？」

「今は非常時ですからね。（パレスチナでインティファーダが始まってからエジプトの民衆レベルに急速に広まったスローガン）分かりました。やりますよ。」

施設で、タスクの本当の身分を知っているのは、本社の人間を除けば支配人だけだ。現地採用の社員、パート、アルバイト等は、タスクのことを契約社員のタミヤだと承知していた。

タスクは、がっかりして元来た道を引き返した。今出てきたばかりの通用口を通り過ぎて、ウォーターフロントの金網に沿って坂を登って行く。やがて屋外プールとテニスコートを見下ろす坂の頂上にたどり着くと、大駐車場を横切って、敷地の外に出る。振り向くと、大浴場の屋上のミナレットが、アクリル・ガラスの大尖塔が陽光を反射してキラリと輝いた。

タスクは、さきほど出会って、トイレ当番を代わってやったラビアのことを考えていた。決して勤勉な社員とはいえなかった。どちらかというと営業向きだろう。実際、元は営業部にいたのだ。が、景気環境の激変にともなう人員整理によって今の部署に移された。年齢からいっても歳若い社員の指導を積極的にしてもらいたいのだが、関心は金持ちの顧客と個人的な関係をつくることばかりに向いている。娘が２人いて、２人とも私生児を出産している。外国の大学を出た才媛なのにどうしてこうなってしまったのか？解雇すれば娘ともども娼婦になることだろう。

タスクは、駐車場の出入り口の前の道路を横切って、向かい側の葡萄園の中に入った。葡萄棚の下を歩いて行くと、途中で棚が途切れて、白いエナメル質の塗料を塗布した塀に沿って走る遊歩道に出た。タスクは歩道に落ちている小石を蹴飛ばしながらスキップした。自然と歌が口からほとばしり出た。

「ワンパク小僧がひとりいた。ワンパク小僧は君だった。家になんかいられなかった。じっとなんかしていられなかった。ナップザックの中に、下着と靴下と、本を一冊放り込み、背中に背負って、外に飛び出すと、困っている人のところへ一走り、困っている人のところへ一走り……」
