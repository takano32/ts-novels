# 全体像と経緯

少年少女文庫がどういうサイトだったか、それをどう復元し、どう WordPress へ移しているかを、時間の順にまとめます。
数値と決定の出典は括弧内の S 番号です。

## 少年少女文庫とは

TS (性転換) 小説の投稿・収蔵サイトです。1997 年に八重洲メディアリサーチが設立し、
`www14.big.or.jp/~yays` で運営を始め、後に `ts.novels.jp` へ移りました。
保守が止まったのち、2021 年頃に消滅しています (S.14)。
運営が八重洲メディアリサーチの手を離れた後の体制について、文書は「別の管理者へ移管」と書いていますが (S.14、S.90)、
所有者は「文庫運営委員会」による運営だったと説明しており、文書の訂正は所有者の確認待ちです (S.109、T.27.4)。

投稿のピークは 2001〜2007 年で、2014 年に新しい投稿が止まりました (S.50)。

## 所有者レビュー (2026-10-26)

T.10 まで作った状態で所有者レビューに出し (S.92、S.203)、八重洲さんからコメント 11 件と質問 1 件を受けました (S.43)。
設計の改訂章 S.43 で、方針レベルで次の 6 点を決めています。

1. 取り下げた作品と旧版は、消さずに非公開 (`private`) にし、運営委員のロールでログインすれば読めるようにする。
   読者には WordPress が 410 (取り下げ) か新版への 301 (旧版) を返す
2. 削除依頼に「72 時間以内」と約束するのをやめ、専用フォーム → 確認メール → 10 日後に自動で非公開
   → 運営委員が承認・却下・復帰で上書き、という仕組みにする
3. 同じ作品の版違いは掲載日の新しい版を残し、古い版は運営委員だけが読める
4. 作品のまとめ方 (シリーズの束ね方) を人手で直せるようにする
5. Marie 氏の作品をすべて取り下げる (旧サイト時代の申し出を引き継ぐ)
6. サイドバーの「オススメの環」を外して「オーナー作品集」を足す。「文庫前史 (1999)」を「にせ乙女パラダイス」に改める

あわせて、所有者が心配していた「CGI のスクリプトがそのまま落ちてくる」件を全数調べ、
ソースコードやパスワードの流出は無いと確かめました (S.110)。

対応の順番と依存関係は S.99 にあります。要点は、運営委員のロールと非公開の仕組み (T.23) が
Marie 氏の作品の閲覧・版違い・取り下げフォームの共通の土台になること、
作品のまとめ直し (T.24) を版違いの整理 (T.25) より先に行うことです (S.99)。
