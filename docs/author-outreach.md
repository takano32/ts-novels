# 作者連絡と原本照会の計画

本プロジェクトは八重洲メディアリサーチ(少年少女文庫の設立母体)の持ち主の依頼によるリブートである
(設計 v1.3)。八重洲さんは作者への連絡に前向きだが、**連絡手段が不明な作者も多い**。
本書はその整理と、実際に連絡する前に確認しておくべき事項をまとめる。
用語 (本館 = 移築先の WordPress / 別館 = 原本を保つ GitHub Pages ミラー / 旧館 = 消滅した原サイト、
ほか) は [`glossary.md`](glossary.md) が正典。**この 3 語は内部用語**なので、
作者へ送る文面にも書かない (「復元したミラー」「当時のページ」のように具体的に書く)。

## 0. 最優先: 八重洲さん本人への照会(作者連絡より先)

八重洲さんは**元運営者**である。以下は作者連絡より遥かに大きな成果につながる可能性があり、
外部探索では絶対に得られない。作者連絡の前に必ず確認したい:

1. **サーバのバックアップ・ローカル控えは残っていないか**
   → 本ミラーで**未回収のまま確定している 186 話**(ヴィスティア 07/08/10/12–16、ざしきわらし全 13 話、
   デュアルワールド全楽章、きらいなもの 13 話ほか)が一発で戻る可能性がある。
   我々は Wayback・CommonCrawl 全 127 コレクション・ウェブ魚拓・archive.today・Memento・
   生存サーバ・作者サイトを全数照会して「Web 上には存在しない」ことを確定させた。
   **残る可能性は運営者の手元だけ**
2. **`manage2.cgi` の目録データベース**(lib*.html を生成していた元データ)
   → 現在は HTML から機械パースして 3,844 話の目録を再構成しているが、元 DB があれば
   正規化済みの正データが得られる。作品の登録日時・作者ID・ジャンル語彙の統制表も期待できる
3. **感想掲示板 (Crocus BBS) の生ログ**
   → 現在の 3,978 投稿は「各板の最新 100 件スナップショット + res ページ」の合成。
   生ログがあれば失われた投稿が復活する
4. **当時の作者連絡先台帳**(投稿受付時のメールアドレス等)
   → 下記 Tier C(36 名・87 話)の作者に連絡する唯一の手がかりになりうる。
   ただし取り扱いは慎重に(第三者の個人情報。公開はせず連絡にのみ使用)
5. **~yays 側の未公開領域**(www14.big.or.jp/~yays は現在も生きており 2025-10 更新)
   → ギャラリー原寸画像や、公開ディレクトリ外に残る文庫関連ファイルの有無

## 2. 連絡の順序と方針

1. **八重洲さんに §0 を照会**(バックアップ・DB・台帳)— 作品が直接戻る可能性を先に潰す
2. **Tier A に連名で告知**(文庫からの再開のお知らせとして)。許諾が取れた作者から公開解禁
3. **Tier B / C は八重洲さん経由**。当時の台帳が使えるなら、そこから順次
4. **保留中の具体案件**: おもちばこさんの pixiv 再掲 2 作(雨女・きらいなもの→ＧＷ)は
   本人がプロフィールで転載前連絡を求めているため、許諾が出るまで `~/ts-novels-holding/` に保管し
   公開しない(denylist 相当)

**エージェント・自動処理は作者に一切連絡しない。** 連絡は takano32 または八重洲さんが人として行う。

## 5. 運営の移管と、データを持っている可能性のある人(2026-08-30 追記)

**経緯の正確な理解**: 八重洲メディアリサーチ(八重洲一成氏)が少年少女文庫を**設立**し、
`www14.big.or.jp/~yays` で運営 → その後**別の管理者へ移管** → 移管先の管理者が
メンテナンスをやめ、2021 年頃にサイト消滅 → 現在、設立者である八重洲さんの依頼でリブート中。

この経緯は §0 の照会先を分岐させる:

| 欲しいもの | 持っている可能性が高いのは |
|---|---|
| ~yays 時代(1999〜2003 頃)のファイル・ギャラリー原本 | **八重洲さん**(自分が運営していた期間。~yays は現在も生きている) |
| **未回収 186 話の原本**(2005〜2013 投稿が中心) | **移管先の管理者**(ts.novels.jp 時代のサーバを握っていた人) |
| `manage2.cgi` の目録 DB・感想板の生ログ | 同上(移管先の管理者) |
| 当時の作者連絡先台帳 | 両方の可能性。移管時に引き継がれていれば移管先 |
| 2018 年の再建版 `ts-novels.jp` の素材 | 再建を試みた人物(移管先本人か別の有志か要調査) |

**したがって八重洲さんへの照会には、次の 2 点を必ず含めたい**:
1. ご自身の手元に残っている ~yays 時代のファイル・作者連絡先の控え
2. **移管先の管理者は誰で、連絡は取れるか**(その人がサイト消滅時のサーバデータを持っている可能性。
   コンタクトが取れれば、未回収 186 話が戻る最大の望み)

移管先管理者の同定は、ミラー内の一次資料(運営日記 `dialy/`・編集"好"記 `comittee/`・
運営掲示板 `~ts/bbs/index@log_data1`・新着情報 CGI・トップページの著作権表記の変遷・
後継ドメイン `ts.novels.name` / `ts.raa0121.info` / `ts-novels.jp` の主体)から
プロジェクト側でも調査を進めている。判明した候補は別途報告する。
