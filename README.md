# 少年少女文庫 — ts.novels.jp 復元ミラー

閉鎖された TS（性転換）小説投稿・収蔵サイト **「少年少女文庫」**（`http://ts.novels.jp/`, 2002–2021 頃）を、
複数の Web アーカイブのスナップショットから復元した静的ミラーです。

元サイトは既に消滅しており、本リポジトリは
[Internet Archive Wayback Machine](https://web.archive.org/) を主軸に、
[CommonCrawl](https://commoncrawl.org/)・[archive.today](https://archive.today/)・親サイト `www.novels.jp`・
さらに**各作品の原作者サイト**に残された記録を横断的に収集して再構成したものです。
Wayback に存在しなかったページも、ありとあらゆるアーカイブ・原典から可能な限り回収しています。

## 内容

- **全 8,548 コンテンツファイル**（HTML 3,731 / CGI出力のHTMLスナップショット 4,032 / 画像 781 / その他）
- トップページ `index.html`、目次 `lib*.html` / `lib-index-*.html`、作品本体 `novel/YYYYMM/<投稿ID>/<作品>.html`
- Wayback の ts.novels.jp ミラー（status 200 全 3,828 件）に加え、複数の手段で **計 約4,712 ページを追加回収**:
  - **103 ページ** … CommonCrawl（Wayback 未収録の作品本体）。うち 1 件（ヴィスティア chapter 11）は
    2013 年以前の旧クロール CC-MAIN-2012 のみに現存し、インデックス API 停止中のため
    `data.commoncrawl.org` の zipnum cdx を直接照会して発見・ARC レンジリクエストで回収した
  - **653 ページ** … 親サイト `www.novels.jp/~ts/`（ts.novels.jp の元となった旧ホーム。作品別の読者**感想掲示板** 304 板、過去ログ掲示板 `2ndbbs`、コラム・日記など、ミラーに無かったコミュニティ層）
  - **約 598 ページ** … 各作品の**原作者サイト**（Wayback にも CommonCrawl にも ts.novels.jp 版が残っていなかった作品を、原作者の個人サイトのアーカイブから回収。分割話の連結や作者カタログ全体の取り込みを含む。下記）
  - **3,359 ページ** … 掲示板の**個別スレッド（`?res=` パーマリンク）**。感想掲示板の個別スレッド 2,866・
    作品紹介掲示板スレッド 489・第二掲示板（ストーリー道場）スレッド 1・2003年当時のトップページ変種 2 ほか。
    当初「全て捕捉時点でエラー」と判定して除外していたが、CDX の記録長分布で再検証したところ
    2002〜2007年のキャプチャに実体（読者の感想スレッド本文）が残っていることが判明し、全量回収した（下記）。

## 復元方法

1. **収集** — Wayback CDX API で `ts.novels.jp` 配下の全 URL を列挙し、ステータス 200 のものを対象に選定。
   各 URL は原則として**最新の 200 スナップショット**を採用（末尾が切り詰められていた 3 件のみ、完全な旧スナップショットを使用）。
2. **取得** — Wayback の `id_`（raw）モードで取得し、ツールバー等の混入のない**原本バイト**を保存。
   さらに **CommonCrawl の全インデックス（2008–2025、全 125 種）を横断**して `ts.novels.jp/*` と
   `www.novels.jp/~ts/*` のキャプチャを集約し、
   Wayback に無かったページを WARC/ARC レンジリクエストで本文取得（**103 ページ**を追加回収）。
   archive.today・国立国会図書館 WARP・ウェブ魚拓（megalodon.jp）も照会したが、いずれも追加分は無し
   （archive.today の 7 件はすべて Wayback と重複）。
   - **親サイト `www.novels.jp`** … ts.novels.jp は `www.novels.jp/~ts/` の別名（vhost）だった。
     旧ホーム `~ts/` 配下に残る読者**感想掲示板**（作品別 304 板）・過去ログ・コラム等 **653 ページ**を Wayback id_ で回収
     （個別投稿 permalink `?res=` は捕捉時点で既に 404 のエラースタブだったため除外）。
   - **掲示板個別スレッド（`?res=` パーマリンク）の全量回収** … 掲示板の板ページ（`?log=`）は初期回収で
     収蔵済みだったが、個別スレッド permalink（`?res=<投稿ID>`）は「サイト死後の最新キャプチャがエラースタブ
     （280 バイト・「該当記事が見つかりませんでした」）」だったため当初除外していた。本再検証で、URL ごとに
     **全キャプチャの記録長の分布**を確認したところ、3,465 の permalink 中 3,355 は掲示板が生きていた時期
     （2002〜2007）の実体キャプチャ（数KB〜18KB）を持つことが判明。各 URL について「記録長 700 バイト超の
     最新キャプチャ」を採用（エラーページ検出時は次候補へフォールバック）して全量回収した。
     残り 110 は全キャプチャがスタブ長＝捕捉時点で既にスレッドが消えていたもので、回収不能。
     ファイル名は既存の規約（`index@res_<ID>_log_<板>.cgi` 等）に合わせ、既存ページからのリンクがそのまま解決する。
   - **原作者サイト（多エージェント並列探索）** … どのアーカイブにも ts.novels.jp 版が残っていない作品について、
     ミラー内の目次・クレジット（作者名・作者ホームページへのリンク）から原作者の個人サイトを割り出し、
     Wayback に残るその個人サイトから同一作品を回収。作品名・話数・サブタイトルの一致を**本文取得で検証**して対応付け、**約 598 ページ**を回収。
     投稿ディレクトリ（＝1 作者・1 シリーズ）単位で調査を分割し、多エージェントの調査ワークフローで網羅した。
     作者が判明したシリーズは、残りの全話・番外編・作者カタログまで辿って回収している。
     作者サイトで 1 話が複数ページに分割されている場合は連結して 1 ファイルに復元。主な回収元:
     - `sokomono.webcrow.jp` … Boy's Emotion 全 21 パート
     - `einhobby.dousetsu.com` … ドンノルマの使者 全 8 話＋目次
     - `johdan.a.la9.jp` / `homepage3.nifty.com/johdan` … 戦乙女セーラ Vol3〜11（各 4 話連結）・城弾作品群
     - `www3.coara.or.jp` … 機甲天女ヴァルキュリア系 21 件
     - `geocities.jp/izumiyapaamu` … 魔蘭シリーズ・SOAG ほか
     - `www.pluto.dti.ne.jp/~kebochin` … りぼん／闇シリーズ、`din.or.jp/~tarota`・`setsugetsuhuuka.com`・`minafumi.aki.gs`・`yamadatennjuhp.web.fc2.com` ほか多数
3. **文字コード変換** — `nkf` による自動判定で UTF-8 へ統一（元は大半が Shift_JIS、一部 ISO-2022-JP、宣言なしのものも含む）。
   `<meta>` の charset 宣言も UTF-8 に書き換え。
4. **リンク書き換え** — サイト内リンク（絶対 `http://ts.novels.jp/...`、ルート絶対 `/...`、`..` を含むものすべて）を
   ブラウザと同じ規則で解決し、各ファイルからの**相対パス**へ変換。
   これにより、ユーザーページ（ルート公開）でもプロジェクトページ（`/<repo>/` のサブパス公開）でも正しく動作します。

## 検証結果

変換後の全コンテンツ（HTML・CGIスナップショット 7,761 ファイル）に対するリンク監査:

| 項目 | 件数 |
|---|---|
| 解決する内部リンク | 100,189 |
| 内部絶対リンクの書き換え漏れ | 0 |
| サブパスで壊れるルート絶対リンク | 0 |
| ルート外への `..` リンク | 0 |
| 不正な UTF-8 | 0 |

追加回収の積み重ねで、解決する内部リンクは当初の Wayback ミラー時点の **33,729 本から 100,189 本**に増加しました。
なお本監査は当初版より判定を強化しており、`www.novels.jp/~ts` 宛の絶対リンク（4,912 本）の相対化、
引用符なしの属性値（旧目次 `lib8/9/16.html` に潜在していたルート絶対リンク 13 本）の修正も含めて全て 0 を確認しています。
加えて、ローカル HTTP 配信を `/<repo>/` サブパス下で行い、回収ページが 200 応答し内部リンクも解決することを確認済み。

## 既知の欠落・回収範囲について

ここまでの横断回収（Wayback Machine／CommonCrawl／`www.novels.jp`／archive.today／NDL WARP／ウェブ魚拓／
**各原作者の個人サイト**を多エージェントで総当たり）を尽くしてなお、一部の作品・画像は **どこにも実体が残っておらず**辿れません。

未解決だったリンク先（延べ約 7,000 ターゲット）は全数を機械的に分類し、以下を確定しています:
1. **当時すでに消滅**（Wayback に捕捉されたが全キャプチャが 404/403、または全キャプチャがエラースタブ長）
   … 146 件 ＋ 掲示板スレッド 110 板。回収不能。
2. **個別スレッド permalink の未捕捉分** … 1,850 件。掲示板ページが実リンクする `?res=` スレッドのうち、
   どのアーカイブにも一度も捕捉されなかったもの（Wayback が保存したのは全スレッドの一部のみ）。回収不能。
3. **真に失われた作品ページ**（一度も捕捉されず、かつ元サイトのページから実リンクされていたもの）。
   全 76 投稿ディレクトリをエージェントが個別調査し、**37 件を原作者サイトから回収**。残りは
   原作者サイト自体が消滅している・作者が個人サイトを持たなかった（メール連絡先のみ）・
   目次上コメントアウトされた「予定」のまま**一度も公開されなかった**もの、と検証済み。
   回収した BBS スレッドが実リンクする作品 URL も再分類したが、新規の欠落は 4 単位のみで、
   個別調査の結果すべて「実体は収録済み」だった:
   拡張子誤記（`youma*.htm` → 実体 `.html` 収録済み）・タイプミス（`m-vamp03.htm` → `m_vamp03.htm`）・
   改名前の旧 URL（`mirage02.html` → `mirage02.htm`）は本文一致を検証のうえエイリアスを配置、
   運営イベント過去ログ `event02.htm` は**サイト生存中に分割改組で削除**され（当時のキャプチャも 404）、
   後継の分割ログ `event02_1〜5.htm` が収録済み。
4. **画像等の未捕捉** … 約 1,035 件。当時のクローラが画像を保存しなかったもの。回収不能。
5. **幻影・ゴミ** … 原作者サイト由来ページのナビゲーションが指す ts.novels.jp に無かったカタログ（約 1,776）、
   スパム投稿の壊れたマークアップをリンクとして誤認識したもの（約 1,511）。対象外。

また `www.novels.jp/~ts/`（`~ts` のトップ URL）は全キャプチャが**空ボディの 200** であり、
実体はもともと ts.novels.jp/ 側でのみ配信されていたため、復元対象が存在しません。

具体例として、シリーズ目次が参照する `sebaschan.htm` と `ama.htm` の 2 話は、
共同企画「二代目は……」の参加作で、原作者サイト（`minafumi.aki.gs`）には企画ルールページのみが残り
作品本体は収録されていなかったため、回収できませんでした（同シリーズの他 9 話は復元済み）。

また、`cgi-bin/` 配下の掲示板・新着リスト・カウンタ等の動的ページは、当時生成された HTML スナップショットとして保存していますが、
CGI としては動作しません（静的な記録のみ）。

## 公開（GitHub Pages）

`master` ブランチへの push で `.github/workflows/deploy-pages.yml` が動作し、GitHub Pages へ自動デプロイされます。
初回のみ **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** に設定してください。

## リポジトリ構成・履歴

- タグ **`raw-original`** … Wayback 由来分について、UTF-8 変換・リンク書き換えを行う**前**の原本バイト（Shift_JIS 等のまま）。
  変換結果と原本を比較したい場合や、再変換のやり直しに使えます。
  追加回収分（CommonCrawl 102・`www.novels.jp/~ts` 653・原作者サイト 約 598・掲示板スレッド 3,359）も、いずれも
  変換前の生バイト（Shift_JIS / CP932 / EUC-JP）をいったんコミットしてから UTF-8 化しており、
  各 raw コミットが履歴に残っています。
- `.nojekyll` … GitHub Pages の Jekyll 処理を無効化（特殊なファイル名の取りこぼし防止）。
