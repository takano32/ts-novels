# 少年少女文庫 — ts.novels.jp 復元ミラー

閉鎖された TS（性転換）小説投稿・収蔵サイト **「少年少女文庫」**（`http://ts.novels.jp/`）を、
複数の Web アーカイブのスナップショットと作者のサイトに残った記録から復元した静的ミラーと、
それを WordPress のライブラリへ移築する作業のリポジトリです。

- 原本アーカイブ (このリポジトリを GitHub Pages で配信): https://takano32.github.io/ts-novels/
- WordPress への移築先: https://novels.xwp.jp
