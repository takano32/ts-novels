# 少年少女文庫 — ts.novels.jp 復元ミラー

閉鎖された TS（性転換）小説投稿・収蔵サイト **「少年少女文庫」**（`http://ts.novels.jp/`, 2002–2021 頃）を、
複数の Web アーカイブのスナップショットから復元した静的ミラーです。

元サイトは既に消滅しており、本リポジトリは
[Internet Archive Wayback Machine](https://web.archive.org/) を主軸に、
[CommonCrawl](https://commoncrawl.org/)・[archive.today](https://archive.today/)・親サイト `www.novels.jp`・
さらに**各作品の原作者サイト**（アーカイブと、現存する移転先サイト）に残された記録を横断的に収集して再構成したものです。
加えて、文庫の**前世代ホーム**（`www2.tomato.ne.jp/~ezpe` → 八重洲メディアリサーチ `www14.big.or.jp/~yays/`）と
**姉妹・後継ドメイン**（`ts.novels.name`・`kirika.novels.name`・`ts.raa0121.info`・`ts-novels.jp`）を発見・回収し、
サイトの全世代（1999 頃〜2023 頃）を一つのミラーに統合しています。

## 復元方法

1. **収集** — Wayback CDX API で `ts.novels.jp` 配下の全 URL を列挙し、ステータス 200 のものを対象に選定。
   各 URL は原則として**最新の 200 スナップショット**を採用（末尾切り詰めの 3 件のみ完全な旧スナップショット）。
2. **取得** — Wayback の `id_`（raw）モードで取得し、ツールバー等の混入のない**原本バイト**を保存。
   CommonCrawl 全インデックス（2008–2025、全 125 種。旧クロールは zipnum cdx の S3 直接照会）、
   archive.today・国立国会図書館 WARP・ウェブ魚拓・arquivo.pt・Memento aggregator も照会
   （arquivo.pt はキャプチャ無し、その他は Wayback と重複のみ）。
   - **掲示板個別スレッド（`?res=`）の全量回収** … CDX の記録長分布による実体判定
     （エラースタブ ≈ 400B、実体 = 数 KB）で、当初「全てエラー」と誤分類していた 3,355 件を回収。
   - **原作者サイト（多エージェント並列探索）** … ミラー内の目次・クレジットから原作者サイトを割り出し、
     Wayback に残る個人サイトから同一作品を本文照合のうえ回収。作者が判明したシリーズは全話・番外編まで追跡。
   - **前世代・姉妹ドメインの発見** … 収蔵ページの外部リンクとナビゲーション
     （`library.html` の「クリエーターズ・フロア（仮）」「道場（仮）」等）を洗い出し、
     `ts.novels.name`・`ts.raa0121.info` を特定。転載探索の過程で、文庫の設立母体
     **八重洲メディアリサーチのサーバが現在も生存**しており（消失ファイルは広告 soft-404 を返す）、
     Wayback に旧世代の 200 キャプチャが 5,400 超残っていることを発見。`~yays/library/` が本体と
     同一構造であることを利用して、「回収不能」と分類していたフラット時代の作品
     （**憐哀 -RENAI-**・**ザ・ヒロイン** 各話・ときめき・酒・ころも・ウィニングボール・
     スペースソード・no_magic・q-warp ほか）を一括回収した。
   - **現存する作者移転先からの直接回収** … 作者の SNS・なろう ID・移転告知を辿って
     現在も生きている移転先サイトを特定し、失われた章を本人公開版から回収
     （バージョン対応は重複話の本文照合で検証。ホスティング注入の広告 script は除去）。
   - **Apache 標準アイコン** … autoindex が参照する `icons/folder.gif`・`image2.gif` は未捕捉だったが、
     実サーバから回収済みの `back.gif`/`blank.gif`/`text.gif` が Apache 公式ストックと md5 完全一致する
     ことを確認したうえで、同一配布物のストックで補完。
3. **文字コード変換** — 自動判定（UTF-8／CP932／EUC-JP、混在ページは置換文字数最小の解釈）で UTF-8 へ統一。
   `<meta>` の charset 宣言も UTF-8 に書き換え。
4. **リンク書き換え** — サイト内リンク（絶対 URL・ルート絶対・`..` を含むものすべて。
   世代間リンク〔novels.jp ↔ yays ↔ ezpe ↔ novels.name ↔ raa0121.info〕を含む）を
   ブラウザと同じ規則で解決し、各ファイルからの**相対パス**へ変換。
   クエリつき CGI URL は `bbs.cgi?log=X` → `bbs@log_X.cgi` 形式の規約でファイル名化。

## 検証結果

変換後の全テキストコンテンツ（13,176 ファイル）に対するリンク監査:

| 項目 | 件数 |
|---|---|
| 解決する内部リンク | 139,817 |
| 変換対象ファイルの不正な UTF-8 | 0 |
| 収蔵ページの novels.jp 系絶対リンク残り | 0（対象外の管理者個人ページ・外部カウンタ・消失先のみ絶対のまま） |

追加回収の積み重ねで、解決する内部リンクは当初の Wayback ミラー時点の **33,729 本から 139,817 本**に増加しました。
ローカル HTTP 配信を `/<repo>/` サブパス下で行い、回収ページが 200 応答し内部リンクも解決することを確認済み。

## 既知の欠落・回収範囲について

横断回収を尽くしてなお、以下は**どこにも実体が残っておらず**回収できません:

1. **未捕捉の掲示板スレッド** … `?res=` パーマリンク約 1,850・感想板 40 板・
   ラウンジ 97 スレッド・noteky の未捕捉ノートなど、クローラが一度も保存しなかった動的ページ。
   新収蔵の BBS 群が参照する CGI クエリ変種（ページ送り・表示モード等）の未捕捉分も同クラス。
2. **真に失われた作品** … 全アーカイブ・原作者サイト・転載先を探索してなお不明:
   - ヴィスティア chapter 07/08/10, 12–16（ほたる。09 はウェブ魚拓から回収済み。作者は連絡先を一切公開していない稀有な例）
   - 二代目は海女（きりか進ノ介）
   - 倒錯戦隊トランス・ギャルズ／生命戦隊トランスギャルズ（矢治浩平。
     1999 年の開発会議室 BBS が `www2.sts.co.jp/~yaji/cgi-bin/transgals.cgi` の Wayback に 2 枚残るのみ）
   - きらいなもの 第 3,7–16,18,20 話（おもちばこ。5/17 話はウェブ魚拓から回収済み）・１２＋１ 第 2/4 話・デュアルワールド各章（バレット）・
     彼女と僕と僕の生きる道 2–4、世にも奇妙で不幸な物語 ほか
   - なお、これらの一部は**原作者が現在も活動中**であり（なろう・pixiv 等で確認済み）、
     本人への連絡により回収できる可能性が残っています。
3. **画像等の未捕捉** … 約 850 件（当時のクローラが画像を保存しなかったもの）。
4. **幻影・ゴミ** … 原作者サイト由来ページのナビが指す文庫に無かったカタログ、
   スパム投稿の壊れたマークアップをリンクと誤認識したもの。対象外。

また `www.novels.jp/~ts/`（`~ts` のトップ URL）は全キャプチャが空ボディの 200、
`utanotuki.novels.name`（うたのつき Wiki）と `www.novels.name/tsh/` は 200 キャプチャが皆無で、復元対象が存在しません。

`cgi-bin/` ほか各掲示板の動的ページは、当時生成された HTML スナップショットとして保存しており、
CGI としては動作しません（静的な記録のみ）。

## 公開（GitHub Pages）

`master` ブランチへの push で `.github/workflows/deploy-pages.yml` が動作し、GitHub Pages へ自動デプロイされます。
初回のみ **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** に設定してください。

## リポジトリ構成・履歴

- ディレクトリ対応: リポジトリ直下 = `ts.novels.jp/`、`~ts/` = `www.novels.jp/~ts/`、
  `~yays/` = `www14.big.or.jp/~yays/`（`~yays/library/` 相当分は本体ツリーへ統合）、
  `~ezpe/` = `www2.tomato.ne.jp/~ezpe/`、`ts.novels.name/` ほかホスト名ディレクトリ = 各姉妹ドメイン。
- タグ **`raw-original`** … 初期 Wayback 回収分の変換前原本バイト。以後の追加回収分も、
  いずれも**変換前の生バイトを一旦コミットしてから** UTF-8 化しており、各 raw コミットが履歴に残っています。
- `.nojekyll` … GitHub Pages の Jekyll 処理を無効化。
