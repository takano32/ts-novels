Internet User 必携ツール

皆さんもあちこちのWebサイトをうろついたことだと思いますが、私がこの世界に踏み込んで、やっぱり気になるのは課金。初期の頃課金を浮かす方法としてもちいたのが、Netscapeのキャッシュでした。

世の中には有用なサイトも多々ありますが、一度行ったサイトに、何度も何度も課金を払って見に行くのは馬鹿らしいものがあります。ですから、一度行ったサイトをセーブできると非常に便利です。

Netscapeは過去のファイルをキャッシングしていきます。キャッシュを確認しない設定にしておくと、オフライン時でもキャッシュを参照してくれるので、あたかもオンラインのように振る舞ってくれます。CGIを実行したり、Yahoo!の検索がまんま使えるなど、なかなか優秀です。

ところが、これには欠点があります。Netscapeのキャッシュは容量には制限がありませんが、どうやらキャッシングするファイル数に制限があるみたいなのです。従って、使っているうちにキャッシュから読み込んでくれないファイルが出てきます。Netscapeのキャッシュはただ単にHTMLファイルとGIFファイルをそのままファイル名を変更してセーブし、Indexを別に作成し、Indexを参照し、そのファイルを表示しているだけです。ですから、キャッシュからローカルURLを作るのはさぞ簡単だろうとWebサイトをうろついていると、Netscape Cache Converter(こばごんさん作)というシェアウェアを発見しました。

これは、その名の通りNetscapeのキャッシュからローカルなＷｅｂサイトを構築するものです。構築時に、ついでにリンクも変更してくれます。ですから、ハードディスク内のHTMLファイルを見る時に、リンク集などからたどっていった時も、ローカル内のディレクトリに書き換えられているため、ローカル内のそのサイトにきちんと飛んでくれます。Internet Explorerや、Mosaicのバージョンもあります。

実は私は上記のソフトは使っていなくて、ASCII DOS/V ISSUE三月号についていた別のフリーソフトを使っています。上記のソフトは非常に優秀で便利なのですが、今の私にはレジスト料を払う金銭的な余裕がありません。お金に余裕が出来たらきちんとレジストするつもりです。

もう一つ便利なのは、Web巡回ツール。シェアウェア、フリーウェア、パッケージソフトそれぞれでいろいろでています。波乗野郎なんかが有名ですよね。気になる人はYahoo！で"波乗野郎"を叩けば出てきたと思いますので、自力で叩いてください。僕は、あ、このページは全部読みたいなと思うと、この手のツールを使います。会社で専用線を使える人は、こういうツールを使ってダウンロードしておき、FDDでおうちに持って帰ると経済的です。
