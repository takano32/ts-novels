  1. はじめに

    2.  　パソコンのインストールをするのはなかなか骨が折れる。プリインストールマシンの再セットアップ手順を見ると発狂しそうになるぐらい複雑なことも多々ある。このようなとき、僕のLet'sNoteにいたっては、リカバリＣＤを使おうにも、外付CD-ROMを持っていない(※)しかし当然と言うか、やっぱりというかPCMCIAのネットワークカードは持っているので、これを使って別のマシンにバックアップを取るということを行っている。
    　DOSからネットワークにつなげてどういうご利益があるのかだが、次の２点に集約されると思う。

    1. DriveImageなどのバックアップツールのバックアップ先にする
    2. Windows95/98/NTなどをネットワークからインストールする

    特に、物理的にバックアップ用ドライブを持つことの出来ないノートパソコンにおいてはDriveImageを使えばハードディスク換装時に一時的に別マシンにデータを退避することが可能だ。

  2. DOS上のネットワーククライアントの種類

    3. 別にここは僕が書くこともなく、こことか、こことかに詳しく書いてあるのだが、ここは一応説明しておこう。

    1. Lan Manager

      2. ダウンロード先
      • ftp://ftp.microsoft.com/bussys/Clients/LANMAN/DSK3-1.EXE
      • ftp://ftp.microsoft.com/bussys/Clients/LANMAN/DSK3-2.EXE
      • ftp://ftp.microsoft.com/bussys/Clients/LANMAN/DSK3-3.EXE
      • ftp://ftp.microsoft.com/bussys/Clients/LANMAN/DSK3-4.EXE
      対応プロトコル
      • TCP/IP
      • Netbeui
      • IPX/SPX
      インストーラーが変更するファイル
      • config.sys
      • autoexec.bat
      • protocol.ini

      基本版と応用版の二種類があって、ここで僕が問題にするのは基本版のほうである。
      FD一枚に納めたときの容量は実はこれが一番小さかったりするのだが、運用上のフレキシビリティが一番ない。基本版ではログオンプロンプトを表示することが不可能で、応用版はログオンプロンプトを表示することが出来ない。個人的にはあまりお勧めできないクライアントである。しかしDISKに圧縮をかけずにTCP/IPを使うにはこれしかない。
      ちなみに、ADDDRVコマンドで読み込んで運用することが出来るので、圧縮してRAMDISKに展開してからドライバを読み込むことが出来る。

    2. Network Client for DOS

      ダウンロード先

      • ftp://ftp.microsoft.com/bussys/clients/msclient/dsk3-1.exe
      • ftp://ftp.microsoft.com/bussys/clients/msclient/dsk3-2.exe
      対応プロトコル
      • TCP/IP
      • Netbeui
      • IPX/SPX
      インストーラーが変更するファイル
      • config.sys
      • autoexec.bat
      • protocol.ini
      • system.ini
      これも基本版と応用版の二種類があって、応用版ならばドメイン認証が可能だが、基本版で十分だろう。必要なDISK容量はどちらも同じで、system.iniを一箇所変更するだけなのだが、メモリの占有量が違うようだ。ここでも問題にするのは、基本版の方である。
      意外にDISK占有量が多くて、TCP/IP版を使うとフロッピー一枚に入りきらない。PureDOSを使えば問題ないのだが、そうするとFAT32を読み書きできないので、VFATBAKとかYUPDATEなどでバックアップを取ろうとしている人には不向きである。もっとも個人でNetbeuiで問題がある人がいるとは思えない。しかし、ADDDRVで後で読み込むことが可能だから、RAMDISKに展開してADDDRVで読み込めばTCP/IPでも運用が可能だ。なお、Netbeuiを使用する場合は、DISK2のファイルは必要がない。
    3. Network Client for DOS

      ダウンロード先

      • ftp://ftp.microsoft.com/softlib/mslfiles/mswgcn.exe
      対応プロトコル
      • Netbeui
      インストーラーが変更するファイル
      • config.sys
      • autoexec.bat
      • protocol.ini
      一番簡便なものだが、DISK占有量はNetwork Client For DOSと変わらないのでイマイチメリットを感じない。また、これはADDDRVで読み込むとハングするので、運用のフレキシビリティも低い。コマンドもNetwork Client For DOSの方が多いので、僕としてはNetwork Client For DOSを使うことをお勧めする。また、そもそもTCP/IPが使えないので、TCP/IPで運用したい人には意味がない。
