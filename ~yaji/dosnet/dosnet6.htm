1. PCMCIAカードを使おう

    2.  ということで本題のPCMCIAでのネットワーク接続だ。基本的にはPCMCIAのカードはISAのカードと取り扱いが同じである。一般的にPCMCIAのカードは、CardService/SocketServiceを用いて認識させるのが常だが、僕自身はカードイネーブラが存在するLANカードを使うことを薦める。安価な値段で潤沢に流通しているし、この方が扱いが簡単だからだ。Planexのカードや、Melcoのカードには付属しているようである。

    以下は、CyqveのELA-110Eについて説明するが、基本的にはNetwork Client For DOSのインストール(設定変更編)と同じなので、変更点だけ書くことにする。

    1. system.iniの変更

      2. 付属のフロッピーのa:\MSLANMAN\DRIVERS\ETHERNET\LE100にNDISドライバLE100.DOSと、protocol.iniが付属している。
      ディレクトリ \MSLANMAN\DRIVERS\ETHERNET\LE100
      README .TXT ---a 630 99-09-02 17:45
      PROTOCOL.INI ---a 146 99-09-02 17:01
      LE100 .DOS ---a 13760 99-06-04 14:12
      PROTMAN .DOS ---a 13352 96-04-20 11:00
      まずは、LE100.DOSをNetwork Client For DOSをインストールした場所にコピーして、system.iniの[Network Drivers]セクションのnetcard=の右辺をLE100.DOSに変更しよう。
    2. protocol.iniの変更

      3. [MS$ELNK]セクションに、ドライバディスク付属のprotocol.iniをそのままペーストする。
      [MS$ELNK] IOADDRESS = 0x320
      INTERRUPT = 11
      DRIVERNAME = LE100$
      ISAのカードの場合はprotocol.iniのカードに関する記述を書いている場所に、IRQとIOポートアドレスを記述する必要がある。

    3. config.sysの変更

      4. 一般のISAのカードならば、以上で問題ないのだが、PCMCIAのカードの場合はなんとかカードをPCに認識させる必要があり、そのためのドライバがCyqveのELA-110Eには付属している。これをカードイネーブラと呼ぶが、これはカードによって互換性がない。

      ELA-110EのカードイネーブラはA:\ENABLERのLANEN.EXEである。

      lanen /?
      とすると、
      Usage :
      LANEN [/IRQ:dd] [/IOP:xxx] [/SLT:n] [/CBS:OFF]
      LANEN [/HLP] -- Help message
      LANEN [/CHK] -- List PCMCIA environment

      where /SLT:n specify slot number, default is auto-detection.
      /CBS:OFF disable CardBus slot programming, default is enable.
      と表示させる。一行目を見ると、/IRQ:ddで、IRQを指定し、/IOP:xxxとすると、IOアドレスが指定することが分かる。

      ということで、config.sysの

      device=a:\ifshlp.sys
      の前に、このカードイネーブラを登録する。もしconfig.sysが、
      device=a:\himem.sys
      device=a:\ifshlp.sys
      と記述されていたら、a:\にlanen.exeをコピーし
      device=a:\himem.sys
      device=a:\lanen.exe /iqr:11 /iop:320
      device=a:\ifshlp.sys
      と変更し、protocol.iniで指定したIRQ,IOポートアドレスとあわせておく。後はNetwork Client For DOSを再起動すれば、相手先の共有に接続できるはずだ。

    4. 現状の問題点

      5. ノートパソコンで困っていることを一つ挙げておこう。PCMCIAのカードでしか、DOSの接続は成功していない。その他に、MapJapanのMPL-972や、3comのXJ-10Tなどで動作を確認しているのだが、3comの3CXFE575(X-JACK/CardBus/100BASE-TX)ではどうやっても上手くいかない。DOSのクライアントを使いたければ、PCMCIAのカードを選択しろということらしい。

    5. CardBusについての補足(2000/04/25追加)

      6. 前項でCardBusのネットワークカードは使えないと書いたが、どうやらCardBus用のポイントイネーブラというものは存在するようで、それを使えばちゃんと使えることが分かった。

      今回動作を確認した機種は、ACCTONのCheetah Fast EthernetCard-2230で、このカードにはCardBus用のポイントイネーブラが付属しており、手持ちのCF-A1Vで動作試験をしてみたところ、無事に動作した。

      ポイントイネーブラをドライバ組み込み前に動作させなければならない点以外はPCIのカードと同じように扱えるので、やや高めだがお勧めではある。
