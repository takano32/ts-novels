    作成したフロッピーディスクはNetbeuiプロトコルで通信をするもので、接続先のコンピュータにはNetbeuiがインストールされている必要がある。しかし、最近の主流はTCP/IPである。また、あまりないとは思うが、TCP/IPならばルータを超えることが可能だ。僕はルーターの向こうにあるファイルサーバーにこっそりバックアップを取ったりしている（酷い話だ）。
    インストール手順そのものはNetbeuiの時と同じだ。プロトコルの選択のところで、IPX/SPXを削除してTCP/IPをインストールすればよい。そうすれば、autoexec.batとconfig.sysが変更されて、インストールが完了する。ネットワークドライバの変更手順についてはNetbeuiの時と同じで、system.iniを変更すればよい。protocol.iniの変更についてはやや異なる。
    右側にtcpipの場合のprotocol.iniを表示してある。[MS$ELNK]セクションでドライバの名前を変更することは、Netbeuiの場合と同じである。TCP/IPの場合はもちろんのことながら、IPアドレスとサブネットマスク、を指定しなければならない。それは[TCP/IP]セクションの
    SubNetMask0=255 0 0 0
    IPAddress0=0 0 0 0
    DisableDHCP=0
    で行う。DisableDHCPはIPアドレスの自動割当を使うかどうかで、DHCPサーバーがあれば、右辺を０にすればDHCPでIPアドレスの取得を行い、１にすれば固定IPアドレスの設定となる。DHCPオンが０で、DHCPオフが１なので間違えないように。

    SubNetMask0の右辺がサブネットマスクだ。サブネットマスクをスペースで区切って設定する。IPAddress0=の右辺がIPアドレスである。これもスペース区切りで設定しよう。もし、IPアドレス192.168.1.1、サブネットマスク255.255.255.0の場合は、

    SubNetMask0=255 255 255 0
    IPAddress0=192 168 1 1
    DisableDHCP=1
    ということになる。なお、インストーラによりconfig.sysとautoexec.batも変更されている。

    config.sysには、Netbeui版と同様に、

    device=c:\net\ifshlp.sys
    が追加されている。autoexec.batには、
    C:\NET\net initialize
    C:\NET\netbind.com
    C:\NET\umb.com
    C:\NET\tcptsr.exe
    C:\NET\tinyrfc.exe
    C:\NET\nmtsr.exe
    C:\NET\emsbfr.exe
    C:\NET\net start
    が追加されているはずである。
