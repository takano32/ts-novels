1. Network Client For DOSのインストール(設定変更編）

    2.  このままでは、おそらくあなたのコンピュータで起動しても起動することは出来ない。いくつか、c:\netフォルダ内部のファイルを２つ変更する必要がある。そのファイルとは、c:\net\system.iniとc:\net\protocol.iniである。本来ならばインストール途中でダウンロードしたネットワークドライバをインストールする必要があるのだが、この方法を僕はお勧めしない。というのは、設定ファイルの記述が間違っていて、インストーラーに跳ねられることが多いのだ。ここでは、RealtekのRL8139を例にとって、変更箇所を説明しよう。
    1. ドライバのダウンロード
      必要なネットワークドライバは自力で探し出してダウンロードする必要がある。RealtekのRL8139の場合は ftp://ftp.realtek.com.tw/LANCARD/drivers/8139/oem-8139(380).exeからダウンロードできる。ここから、oem-8139(380).exe をダウンロードして、適当なフォルダに解凍しよう。
    2. 必要なフォルダのコピー
      解凍したフォルダ\MSLANMAN.DOS\DRIVERS\ETHERNET\RTL8139には、二つのファイルが入っている。
      PROTOCOL.INIと RTSND.DOS の二つである。このxxxxxxx.DOSと拡張子がDOSであるのがドライバだ。RTSND.DOSをNetwork Client For DOSをインストールした、C:\NETにコピーしよう。
    3. c:\net\system.iniを変更する
      右はインストール直後のc:\net\system.iniだ。ここに
      netcard=elnk.dos
      という記述があるが、ここの右辺を目的のネットワークカードのものに変更する。ここではRTSND.DOSだから、
      netcard=RTSND.DOS
      に修正する。
      [network]
      sizworkbuf=1498
      filesharing=no
      printsharing=no
      autologon=yes
      computername=USER
      lanroot=C:\NET
      username=USER
      workgroup=WORKGROUP
      reconnect=yes
      dospophotkey=N
      lmlogon=0
      logondomain=WORKGROUP
      preferredredir=basic
      autostart=basic
      maxconnections=8

      [network drivers]
      netcard=elnk.dos
      transport=ndishlp.sys,*netbeui
      devdir=C:\NET
      LoadRMDrivers=yes

      [Password Lists]
      *Shares=C:\NET\Shares.PWL
    4. c:\net\protocol.iniを変更する
      右はインストール直後のc:\net\protocol.iniだ。ここに[MS$ELNK]というセクションがあるはずだ。
      ここには、
      DriverName=ELNK$
      INTERRUPT=3
      IOADDRESS=0x300
      DMACHANNEL=none
      DMAMODE=burst
      MAXTRANSMITS=12
       と列挙されている。これらを全て削除して、
      解凍したフォルダ\MSLANMAN.DOS\DRIVERS
      \ETHERNET\RTL8139\protocol.ini
      に書かれている内容をそのままペーストしよう。基本的には
      DriveName=RTSND$
      とだけ書けばよい。ところで、実際に今やってみたら
      [ndishlp$]
      DriverName=ndishlp$
      Bindings=

      [protman$]
      DriverName=protman$
      priority=ndishlp$

      [data]
      version=v4.00.1111
      netcards=

      [NETBEUI$]
      sessions=10
      ncbs=12
      DriverName=NETBEUI$
      Lanabase=0
       がなぜか何度やっても挿入されてしまうのだが、c:\windows\protocol.iniの内容がそのまま挿入されてしまっていたようだ。
      変更前のprotocol.ini

      [network.setup]
      version=0x3110
      netcard=ms$elnk,1,MS$ELNK,1
      transport=ms$ndishlp,MS$NDISHLP
      transport=ms$netbeui,MS$NETBEUI
      lana0=ms$elnk,1,ms$netbeui
      lana1=ms$elnk,1,ms$ndishlp

      [protman]
      DriverName=PROTMAN$
      PRIORITY=MS$NDISHLP

      [MS$ELNK]
      DriverName=ELNK$
      INTERRUPT=3
      IOADDRESS=0x300
      DMACHANNEL=none
      DMAMODE=burst
      MAXTRANSMITS=12
      [MS$NDISHLP]
      DriverName=ndishlp$
      BINDINGS=MS$ELNK

      [MS$NETBEUI]
      DriverName=netbeui$
      SESSIONS=10
      NCBS=12
      BINDINGS=MS$ELNK
      LANABASE=0
      変更後のprotocol.ini

      [network.setup]
      version=0x3110
      netcard=ms$elnk,1,MS$ELNK,1
      transport=ms$ndishlp,MS$NDISHLP
      transport=ms$netbeui,MS$NETBEUI
      lana0=ms$elnk,1,ms$netbeui
      lana1=ms$elnk,1,ms$ndishlp

      [protman]
      DriverName=PROTMAN$
      PRIORITY=MS$NDISHLP

      [MS$ELNK]
      ;
      ; RTL8139 PROTOCOL.INI Sample
      ;

      DriverName = RTSND$
      [MS$NDISHLP]
      DriverName=ndishlp$
      BINDINGS=MS$ELNK

      [MS$NETBEUI]
      DriverName=netbeui$
      SESSIONS=10
      NCBS=12
      BINDINGS=MS$ELNK
      LANABASE=0

    5. 動作テスト
       設定ファイルの変更が終わったら、再びcommand prompt onlyで起動しよう。そうすると、アカウントとパスワードを聞いてくるはずだ。もし接続先のコンピュータにアカウントとパスワードが必要ならば（たとえば、Windows NT Workstationや Windows NT Serverなど）、相手に登録しているアカウントをここで入力しよう。
      ログオンが完了したら、net use コマンドで、目的の共有を接続する。書式は、
      net use ドライブ名 \\コンピュータ名\共有名
      だ。例えば、コンピュータBASEの共有VOL1を覗く場合は、
      net use L: \\base\vol1
      と入力すれば、L:ドライブに、相手のコンピュータのファイルが見えるはずである。

  2. フロッピー一枚に収める

    1. まずフロッピー一枚をシステム付でフォーマットする。
      format a: /s
    2. 次に、himem.sys をコピーしよう
      copy c:\windows\himem.sys a:
    3. 次に、c:\netの中身をコピーする。
      まず、フロッピーにフォルダを作ろう。フォルダ名は何でもいい。
      mkdir a:\net
      この例ではA:\netというフォルダを作った。 次にそのフォルダにファイルをコピーする。以下のファイルを全てコピーしよう。他のファイルは必要ない(はずだ…)
      PROTOCOL.INI
      PROTMAN.DOS
      PROTMAN.EXE
      NDISHLP.SYS
      NET.MSG
      NETH.MSG
      NET.EXE
      IFSHLP.SYS
      RTSND.DOS
      SYSTEM.INI
      WFWSYS.CFG
    4. system.iniファイルを変更する
      system.ini中にドライバ群の位置を記述している場所がある。ここをフロッピーのコピーしたパスに変更する。今回はa:\netなので
      lanroot=C:\NET
      devroot=C:\net
      の二箇所を、これを、共に
      lanroot=A:\NET
      devroot=A:\net
      に変更しよう。
      [network]
      sizworkbuf=1498
      filesharing=no
      printsharing=no
      autologon=yes
      computername=USER
      lanroot=A:\NET
      username=USER
      workgroup=WORKGROUP
      reconnect=yes
      dospophotkey=N
      lmlogon=0
      logondomain=WORKGROUP
      preferredredir=basic
      autostart=basic
      maxconnections=8

      [network drivers]
      netcard=elnk.dos transport=ndishlp.sys,*netbeui
      devdir=A:\NET
      LoadRMDrivers=yes

      [Password Lists]
      *Shares=C:\NET\Shares.PWL
    5. config.sysファイルを記述する。
      さし当たっては以下のように書いておけば十分だ。
      FILES=10
      BUFFERS=20
      device=a:\himem.sys
      device=a:\net\ifshlp.sys
      二行目のifshlp.sysの場所は、ファイル群をコピーした場所である。a:\netの部分は適時変更すること。

    6. 動作試験
      フロッピーディスクを挿入し起動したら、
      cd a:\net[enter]
      net start
      と入力する。無事ログオン要求が現れたら問題ない。後はnet useコマンドで目的の共有を接続すればよい。
