# S.206 原本アーカイブの復元方法

- 種類: 記録
- 状態: 有効
- 出典: ルートの README.md の「復元方法」(2026-10-26 にここへ移した)
- 関連: T.1, T.2, T.3, T.4, S.17, S.205, S.209

## 復元方法

1. **収集** — Wayback CDX API で `ts.novels.jp` 配下の全 URL を列挙し、ステータス 200 のものを対象に選定。
   各 URL は原則として**最新の 200 スナップショット**を採用（末尾切り詰めの 3 件のみ完全な旧スナップショット）。
2. **取得** — Wayback の `id_`（raw）モードで取得し、ツールバー等の混入のない**原本バイト**を保存。
   CommonCrawl 全インデックス（2008–2025、全 125 種。旧クロールは zipnum cdx の S3 直接照会）、
   archive.today・国立国会図書館 WARP・ウェブ魚拓・arquivo.pt・Memento aggregator も照会
   （arquivo.pt はキャプチャ無し、その他は Wayback と重複のみ）。
   - **掲示板個別スレッド（`?res=`）の全量回収** … CDX の記録長分布による実体判定
     （エラースタブ ≈ 400B、実体 = 数 KB）で、当初「全てエラー」と誤分類していた 3,355 件を回収。
   - **原作者サイト（多エージェント並列探索）** … ミラー内の目次・クレジットから原作者サイトを割り出し、
     Wayback に残る個人サイトから同一作品を本文照合のうえ回収。作者が判明したシリーズは全話・番外編まで追跡。
   - **前世代・姉妹ドメインの発見** … 収蔵ページの外部リンクとナビゲーション
     （`library.html` の「クリエーターズ・フロア（仮）」「道場（仮）」等）を洗い出し、
     `ts.novels.name`・`ts.raa0121.info` を特定。転載探索の過程で、文庫の設立母体
     **八重洲メディアリサーチのサーバが現在も生存**しており（消失ファイルは広告 soft-404 を返す）、
     Wayback に旧世代の 200 キャプチャが 5,400 超残っていることを発見。`~yays/library/` が本体と
     同一構造であることを利用して、「回収不能」と分類していたフラット時代の作品
     （**憐哀 -RENAI-**・**ザ・ヒロイン** 各話・ときめき・酒・ころも・ウィニングボール・
     スペースソード・no_magic・q-warp ほか）を一括回収した。
   - **現存する作者移転先からの直接回収** … 作者の SNS・なろう ID・移転告知を辿って
     現在も生きている移転先サイトを特定し、失われた章を本人公開版から回収
     （バージョン対応は重複話の本文照合で検証。ホスティング注入の広告 script は除去）。
   - **Apache 標準アイコン** … autoindex が参照する `icons/folder.gif`・`image2.gif` は未捕捉だったが、
     実サーバから回収済みの `back.gif`/`blank.gif`/`text.gif` が Apache 公式ストックと md5 完全一致する
     ことを確認したうえで、同一配布物のストックで補完。
   - **CommonCrawl 全 127 コレクションの完全走査（第4次で完遂）** … 欠落 2,993 URL について、
     index API を使わず各コレクションの `cluster.idx` を HTTP レンジ二分探索し、該当 cdx
     ブロックだけをレンジ取得して照会（`scripts/cc_zipnum_sweep.py`）。2008–2026 の全 127
     コレクションを完走し、**既回収分を超えるヒットはゼロ**。CommonCrawl 経路はこれで枯渇。
   - **CDX 全ダンプ × リポジトリ突き合わせ（第3次）** … 全ホスト系統の Wayback CDX を
     ドメイン／プレフィックス単位で全量ダンプ（8 系統・105,287 行）し、URL→リポジトリ規約名の
     写像で**未収ファイルを機械列挙**。status 200 の最良キャプチャ（HTML は length>700 の最新、
     再生 404 は別タイムスタンプへ自動フォールバック）を keep-alive 並列で一括取得し、
     エラースタブ（本文マーカー判定）133 件を除外のうえ収蔵。回収・監査・変換の一式は
     `scripts/` に収録（audit_full / cdx_dump / cdx_recover / wb_fetch / wb_retry /
     place_convert / fix_links / gapfill_basename / live_probe / megalodon_probe）。
3. **文字コード変換** — 自動判定（UTF-8／CP932／EUC-JP、混在ページは置換文字数最小の解釈）で UTF-8 へ統一。
   `<meta>` の charset 宣言も UTF-8 に書き換え。
4. **リンク書き換え** — サイト内リンク（絶対 URL・ルート絶対・`..` を含むものすべて。
   世代間リンク〔novels.jp ↔ yays ↔ ezpe ↔ novels.name ↔ raa0121.info〕を含む）を
   ブラウザと同じ規則で解決し、各ファイルからの**相対パス**へ変換。
   クエリつき CGI URL は `bbs.cgi?log=X` → `bbs@log_X.cgi` 形式の規約でファイル名化。
