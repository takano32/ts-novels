## 運営の移管と、データを持っている可能性のある人(2026-08-30 追記)

**経緯の正確な理解**: 八重洲メディアリサーチ(八重洲一成氏)が少年少女文庫を**設立**し、
`www14.big.or.jp/~yays` で運営 → その後**別の管理者へ移管** → 移管先の管理者が
メンテナンスをやめ、2021 年頃にサイト消滅 → 現在、設立者である八重洲さんの依頼でリブート中。

この経緯は S.85 の照会先を分岐させる:

| 欲しいもの | 持っている可能性が高いのは |
|---|---|
| ~yays 時代(1999〜2003 頃)のファイル・ギャラリー原本 | **八重洲さん**(自分が運営していた期間。~yays は現在も生きている) |
| **未回収 186 話の原本**(2005〜2013 投稿が中心) | **移管先の管理者**(ts.novels.jp 時代のサーバを握っていた人) |
| `manage2.cgi` の目録 DB・感想板の生ログ | 同上(移管先の管理者) |
| 当時の作者連絡先の名簿 | 両方の可能性。移管時に引き継がれていれば移管先 |
| 2018 年の再建版 `ts-novels.jp` の素材 | 再建を試みた人物(移管先本人か別の有志か要調査) |

**したがって八重洲さんへの照会には、次の 2 点を必ず含めたい**:
1. ご自身の手元に残っている ~yays 時代のファイル・作者連絡先の控え
2. **移管先の管理者は誰で、連絡は取れるか**(その人がサイト消滅時のサーバデータを持っている可能性。
   コンタクトが取れれば、未回収 186 話が戻る最大の望み)

移管先管理者の同定は、ミラー内の一次資料(運営日記 `dialy/`・編集"好"記 `comittee/`・
運営掲示板 `~ts/bbs/index@log_data1`・新着情報 CGI・トップページの著作権表記の変遷・
後継ドメイン `ts.novels.name` / `ts.raa0121.info` / `ts-novels.jp` の主体)から
プロジェクト側でも調査を進めている。判明した候補は別途報告する。
