## TASKS.md と文書 (S) の分担

`TASKS.md` は完了した大項目を消してよい運用にするため、**TASKS.md を消しても失われる情報が無い**ように受け持ちを分ける。

| 情報の種類 | 置き場所 |
|---|---|
| 何をやるか・完了条件・参照先 (現在地) | `TASKS.md` の各行 (ここだけ) |
| 完了した大項目の記録 (T1〜) | S156〜S169 (細部は S170〜S204・S205〜S208 の来歴) |
| 方針と決定 | S20〜S43 の改訂章 (S43 まで) |
| 所有者レビューの解析・決定の根拠・実測値・質問 | S98〜S115 |
| 判定基準・閾値・状態遷移・権限・ファイル形式・コマンド仕様 | 4 本の仕様書 (visibility-roles / takedown-form / versions / cluster-overrides) |
| 受け入れ条件と実測値 (実装の細部) | S6〜S12・S44〜S48・S170〜S204 |
| 恒久的な手順 | runbook 3 本 (publish / removal / rebuild) と S82〜S84 |
| サーバの事実・収蔵物の件数・用語 | S59〜S68 / S49〜S58 / S14〜S19 |
