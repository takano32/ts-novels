## WP サイト・原本アーカイブ・旧サイトの呼び分け(**内部用語。利用者に見せる文面では使わない**)

プロジェクト内の文書・コミットメッセージ・コード中では次の 3 語で呼び分ける。
**サイト上の表示文言・about ページ・バナーなど、読者の目に触れる場所では使わない**こと
(読者には「原本を見る」「当時のページ」のように、具体的に何であるかを書く)。

| 語 | 指すもの | 実体 |
|---|---|---|
| **WP サイト** | 移築先の WordPress ライブラリ | `novels.xwp.jp`。目録データで体系化した読書・発見の層 |
| **原本アーカイブ** | 原本をそのまま保つミラー | 現行の GitHub Pages(全 17,000 ファイル超)。当時の URL 空間を改変せず保持する。WP サイトに載せられないもの(`.cgi` を含む URL は移築先が 403 にする)もここで生きる |
| **旧サイト** | サルベージ元 = 消滅した原サイト | `ts.novels.jp` とその全世代(前史 `~ezpe`・八重洲期 `~yays`・閉鎖後の姉妹ドメイン)。**もう存在しない**。「旧サイトにはあったが回収できていない」のように使う |

WP サイトの各話から「原本を見る」で原本アーカイブへ、原本アーカイブからはバナーで WP サイトへ、相互に往還する。
(2026-08-30 に旧称カタカナ語・「整理版」から本語彙へ置き換えた)
(2026-10-26 に、それまでの呼び名「本館」「別館」「旧館」をそれぞれ WP サイト・原本アーカイブ・旧サイトに置き換えた。古いコミットメッセージやコードのコメントには前の呼び名が残っている。なお「原本アーカイブ」は読者向けの表示文言 (`/archive/` の題など) としても使っている)
