## 純粋な関数に出したときの判断 (T45.1.16 以降)

- `TS_Episode_Fields::body` (T45.1.16.2) は `--bodies` の有無を 3 つ目の引数 `$bodies` で受ける。状態とペイロードの 2 つだけでは「メタのみ投入 (null)」と「ペイロードが無い (案内文)」を分けられないため。ペイロードのファイルを読むのは `includes/commands/import.php` に残し、取り下げ対象なら読まないのも分割前と同じ。
- `TS_Work_Index::parent_term_values` (T45.1.16.3) は、連載の親 work に合併する値を work ごとに束ねずに、話ごと (episodes の添字 => work と taxonomy ごとの値) に返す。import は分割前と同じく話ごとに `TS_Term_Resolver::term_ids` を呼び、term ID で束ねる。束ねてから 1 度に呼ぶと、解決できなかった値を数える順 (`ts_term_warnings` と警告の「上位」の並び。`arsort` は同点なら入れた順) が変わるため。
- `wp ts verify` の親 work の期待値 (`TS_Verify_Expect::assignment_counts` の `parent_expect`) は `parent_term_values` を使わず、別の実装のまま残す。verify の役目は importer と独立に数え直して取り違えを見つけることで、同じ関数を使うと importer の誤りを期待値も写してしまう。
