## TASKS.md と文書 (S) の分担

`TASKS.md` は完了した大項目を消してよい運用にするため、**TASKS.md を消しても失われる情報が無い**ように受け持ちを分ける。

| 情報の種類 | 置き場所 |
|---|---|
| 何をやるか・完了条件・参照先 (現在地) | `tasks/T.n.md` の各行 (大項目ごとに 1 ファイル。ここだけ)。一覧・状態・実行計画は `TASKS.md` (2026-10-30 に T.22.7 で更新) |
| 人が通して読む説明 (要約) | `docs/` (一覧は `DOCS.md`)。S と tasks/ からの要約で仕様の正ではなく、docs にしか無い情報を作らない |
| 説明文書の一覧と、いまどこにいるかの要約 | `DOCS.md` (現在地は TASKS.md の状態に合わせる。S.219) |
| 仕様 S の一覧と文書の体系の決まり | `SPECS.md` (冒頭の決まり) |
| 完了した大項目の記録 (T.1〜) | S.156〜S.169 (細部は S.170〜S.204・S.205〜S.208 の来歴) |
| 方針と決定 | S.20〜S.43 の改訂章 (S.43 まで) |
| 所有者レビューの解析・決定の根拠・実測値・質問 | S.98〜S.115 |
| 判定基準・閾値・状態遷移・権限・ファイル形式・コマンド仕様 | 4 本の仕様書 (visibility-roles / takedown-form / versions / cluster-overrides) |
| 受け入れ条件と実測値 (実装の細部) | S.6〜S.12・S.44〜S.48・S.170〜S.204 |
| 恒久的な手順 | runbook 3 本 (publish / removal / rebuild) と S.82〜S.84 |
| サーバの事実・収蔵物の件数・用語 | S.59〜S.68 / S.49〜S.58 / S.14〜S.19 |
