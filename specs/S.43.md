## v1.6 改訂: サイト所有者レビューへの対応 (2026-10-26)

### 決定

1. **取り下げ・旧版の非表示は `private` + 可視性メタ**にし、**ロール「運営委員」**がログインすれば読める。
   読者への応答は WordPress が返す (取り下げ = 410、旧版 = 新版へ 301)。
   `.htaccess` の `Redirect gone` は WordPress を経由しない画像資産 (`/assets/annex-img/`) に限る。
   原本アーカイブ (GitHub Pages) はログイン制御ができないので、取り下げ分はビルド除外 (404) のまま、旧版は原本としてそのまま置く。
2. **削除依頼の 72 時間 SLA を撤回する。** 代わりに `/takedown/` の専用フォーム → 確認メール →
   **10 日後に自動で非公開** → 運営委員が承認 (即時) / 却下 (停止) / 復帰で上書きする仕組みにする。
   「GitHub Issue 窓口は不採用」(S.28) は維持 — 現在の `/takedown/` ページが Issue を案内しているのは誤りで、
   かつ Issue 自体が無効になっている。公開面・連絡文・ランブックから「72 時間」の記述 (14 ファイル 33 箇所) を外す。
3. **同一作品の版違いは掲載日の新しい版を残し、古い版は運営委員のみ閲覧**。
   これは「掲載しない」ではなく**版の整理**であり、v1.4 最大掲載原則の例外 3 つには加えない
   (旧版は原本アーカイブに常設、URL は新版へ転送)。判定は 作者 × 正規化題名 × 本文類似度、
   自動確定は本文一致・類似度 ≥0.95、残りは人手確認。
4. **作品クラスタの人手修正を可能にする** (`work_overrides.yml` に分割・併合・切り離し)。
   T.7.5.1 (S.176) で裁定したのは slug だけで、クラスタ本体は未確認だったことを記録する。
5. **Marie 氏の全作品を取り下げる** (旧文庫時代の作者本人の申し出を引き継ぐ。TD.14、author 単位)。
6. 表示の修正: サイドバーの「オススメの環」を外し「オーナー作品集」(八重洲二世 = `/authors/yays/`) を足す。
   「文庫前史 (1999)」は **「にせ乙女パラダイス」** に改称 — `~ezpe/yasai/` は文庫の前身ではなく、
   文庫と並行して運営された姉妹サイト (所有者の証言、原本の `<title>` と一致)。
