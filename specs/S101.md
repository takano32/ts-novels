## サイドメニューの「オススメの環」は不要

**現状**: `ts_bunko_sidebar()` (いまは `mu-plugins/ts-library/includes/render/render-sidebar.php`、項目の表は `includes/render/render-text.php` の `TS_Render_Text::SIDEBAR_INDEXES`) の項目に
`['osusume', 'オススメの環']`。本番の全ページに表示中 (実測: `/about/` の HTML に 1 箇所)。
索引ページ `/index/osusume/` 本体は、種類の表 `TS_Index_Text::KINDS` と題名の表 `TS_Index_Text::TITLES` (`includes/indexes/index-text.php`)、ルーティング (`includes/indexes/index-routing.php`)、描画の `ts_bunko_index_osusume` (`includes/indexes/index-render.php`) (200、226KB)。
作品ページ末尾の「この作品からのオススメ」(`includes/render/render-work.php` の `ts_bunko_osusume`) は別の部品。

**仕様**: サイドバーの 1 行を外す。`/index/osusume/` の URL は残す (S92〜S97 の URL 一覧に載せた URL を
いきなり 404 にしない。索引からは辿れなくなる)。作品ページの「この作品からのオススメ」は維持。

**未決**: 一覧ページ自体も不要なら `TS_Index_Text::KINDS` から外して 404 にする (1 行)。
**規模**: 1 行 + テーマ/mu-plugin の配備 1 回。
