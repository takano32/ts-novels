## 文書の役割と「優先する文書」

**優先する文書 = その事柄について最終的にどれを信じるか。** 文書間で食い違ったら、下表の優先する文書が勝ちます。

### 設計の章の読み方(重要)

設計 (S.20〜S.43) は**改訂を追記する形式**です。同じ論点について複数の記述がある場合、**新しい章が勝ちます**:

| 章 | 内容 | 前章のどこを覆したか |
|---|---|---|
| 本文 (S.20〜S.34) | 4 設計案 → 3 審査員 → 統合した基本設計 | — |
| **S.35** | Xserver for WordPress の実測に基づく再設計 | 公開面を静的書き出しからライブ WP へ。原本アーカイブは GitHub Pages 恒久併存 |
| **S.36〜S.39** | 本文 Markdown 正準化 / 感想板の近代ビュー | 「本文 raw 一律」「感想板はリンクのみ」を撤回。**同じ改訂の章が 2 本あるが後半の 2 章 (S.37・S.38) を優先** |
| **S.40** | 原運営者公認のリブートとして再定位 | 「黙認ベースの運用」という前提を更新。要決定事項 (S.34) の回答を確定 |
| **S.41** | **最大掲載原則** | 「WP 化は作品層のみ・残り 70% は原本アーカイブに凍結」を撤回。掲載しない例外は 3 つだけ |
| **S.42** | 公開前提 | 「全域 noindex → 段階解禁」を撤回。恒久 noindex は掲示板層のみ |
| **S.43** | **所有者レビュー (2026-10-26) への対応** | 72h SLA を撤回しフォーム → 10 日後自動非公開 + 運営委員のオーバーライドへ。取り下げ・旧版は private で運営委員のみ閲覧 (読者には WP が取り下げ 410・旧版 404 を返す。301 は使わない)。版違いは新しい版を残す。「文庫前史」→「にせ乙女パラダイス」 |
