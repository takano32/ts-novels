## 5. コミュニティ層

原則: **「当時の声は史料として見せる。新規の声は受けない。正本は常に原本アーカイブ」**。

- **kansou (作者単位板 289、投稿 2,866 件)**: **インポートも構造化表示もしない。深リンクのみ** (preservation の論拠「板は作者単位で作品単位でない — リンクが最も誠実」を全審査員が支持)。作者ページと各 Episode 書誌カードから該当板ログへ。将来の構造化タブは要決定事項 (実施時も恒久 noindex)。

  > **【失効】** v1.2 改訂章 B により感想板は **`/boards/{作者slug}/` の読み取り専用の近代ビュー**として再現に変更(「作品コメントへの偽装 = 史料改竄」という反対理由は、板を**板として**見せるなら成立しないため。投稿フォームは置かない)。規模も実測で 294 板・約 3,978 投稿に更新。
- **2ndbbs ストーリー道場 (作品 267 + 感想 1,509 件)**: 感想が同一ページ埋込で紐付けが自明な唯一の層。T.36 で CPT `ts_dojo` + 読み取り専用アーカイブコメント (`comment_type='ts_archive'`、原日時・ハンドル保持・メール除去) として取込。カジノ/薬物スパム (13 ページ濃厚汚染) は NG ワード+言語判定でフィルタし、**除外ログ `catalog/dojo_excluded.jsonl` を残す** (何を史料から落としたかの記録 = 説明責任)。
- **~yays noteky f_0 (作品単位感想 63 ノート)**: T.36 で題名の完全一致・非曖昧マッチ分のみ該当 Work ページに「当時の感想 (2001–02 感想ボードより)」の読み取り専用史料ブロックとしてメタ表示 (コメント欄には入れない — 現役機能との誤認防止)。曖昧分は原本アーカイブへのリンクのみ。
- **オススメ作品グラフ (765 エントリ・988 リンク)**: catalog 由来データなので T.10 から。作品ページに出リンク「{推薦者}さんのオススメ」+入リンク「この作品を挙げた読者」、`/index/osusume/` に被推薦ランキング。
- **除外/凍結**: rounge (94% スパム — 実スレ約 20 本の所在は `/annex/` 案内に記載)、~ts/bbs 3 板・resbbs4a・ezpe noteky・newinfo・paintbbs (163+59 枚)・~yays gallery (CG 313 点) は原本アーカイブに凍結。gallery/paintbbs は `/annex/` からギャラリー導線のみ。

  > **【失効】** v1.4「最大掲載原則」により**凍結は撤回**(gallery・道場・noteky・企画/アンソロジーも WP に載せる。載せない例外は denylist / スパム / メールアドレスの 3 つだけ)。除外が残るのは rounge のスパムだけ。なお「~yays gallery CG 313 点」も誤りで、313 は `~yays/gallery/` 区画の**ファイル総数**、CG は `cg/` の 136 点(S.57 (3))。案内ページの URL は `/annex/` ではなく **`/archive/`**(S.200)。
- **新規コメント: 全面閉鎖** (comment_status=closed 強制。rounge の 94% スパム化が実績根拠)。guestbook は静的方針と矛盾するため置かない (審査員1)。連絡は `/takedown/` の運営窓口 (メール+フォーム転送) に一本化し、「感想は作者の現役活動先 (なろう/pixiv、判明分は作者ページに記載) へ」と案内。**GitHub Issue 窓口は不採用** — 削除依頼者の身元と依頼内容を公開の場に晒す (審査員1・3)。
